# 判定台帳

**ユーザーが口にした言葉だけが入る。** シュビーの案はここに書かない（`OPEN.md` に置く）。

## 書き方

- **追記のみ。** 過去の項目を書き換えない。考えが変わったら新しい番号で書く
- **要約しない。** 「なんか怖くない」を「恐怖演出の強度不足」に翻訳した瞬間、判定は失われる。
  次のシュビーが読むのは別の指示になる。言われた言葉をそのまま引く
- **何を見てそう言ったのかを必ず指す。** 出したものが無いと、後から意味が取れない
- 採ったもの（採）と退けたもの（棄）を対で書く。**片方だけだと次に何をすればいいか分からない**
- 矛盾したら**消さずに並べる**。考えが変わった事実そのものが判定材料になる

```
## 0007  2026-08-20  1 周目の暗さ
出したもの: Verification/20260820-2213/lap1_02.png（フル解像度で確認済み）
言葉: 「暗すぎて何が起きてるか分からない。怖い以前に見えない」
棄: 露出を落として画面全体を暗くする方向
採: 光源を 1 つ残して、暗いのは周縁だけにした（20260820-2251）
```

⚠ **ここから原則を作らない。** 1 回の判定は原則ではない。この作品は 1 本しかないので、
作風の原則（STYLE 相当）の層は作らない（`reference/why.md`）。

## 0001  2026-08-08  作りこみの段へ移るにあたって

出したもの: なし（依頼の時点）

言葉:
- 「世界観やデザインの作りこみがまだできていません」
- 「ベースの実装はできたので、この後は作りこみの段階なので企画書を読まないでほしい」
- 「企画書はあくまで企画段階で、今後は企画書を超えた、体験としての世界観、物語性、企画書に無い演出などを
  入れて作りこむ必要があるので、企画書を読むのはコンテキスト汚染になる」
- 「すべては、今の作業コストよりも今後の継続的なシュビーがやりやすい作業環境のため」

棄: 企画書（`docs/proposal/`）を体験の要求の根拠として読むこと
採: まだ無い

⚠ **世界観について言われたのは「まだできていない」と「企画書を超えろ」の 2 つだけ。**
ここから「静けさ」「喪失」「日常の裂け目」のような言葉を作らない。
ユーザーはまだ自分の世界観を言葉にしていない。作って、赤を入れてもらって、初めて言葉になる。

## 0002  2026-08-10  怪異調査員という設定と、隔離

出したもの: なし（依頼の時点）

言葉:
- 「固定カメラプロジェクトの、最初のパススルー→2Dの導入演出と、その前の演出とかも作りこんでおきたい。」
- 「試してみたい設定があって。呪われた壁の呪いを調査してくるという怪異調査員という設定で。
  要は体験者はSCP財団のCクラス職員みたいな感じ。」
- 「呪われた壁は、隔離されている必要があるので、パススルーの段階でも、体験スペースの外側を
  黒い仮想フレームみたいな感じで覆って、中が見えないようにしてみる？」
- 「思想から設計まで考えてみて、実装までして実機での動作検証までお願い。」

⚠ 3 つ目は**語尾が「〜してみる？」**。判定ではなく提案として言われている。
実装したのはシュビーの解釈なので、赤が入る余地がある方に読むこと。

棄: まだ無い
採: 隔離を実装した（`ContainmentShell`。線を越えた瞬間に会場が黒へ落ち、
    実物の壁と足元の床と自分だけが残る）。R001 で焼いた

⚠ **「Cクラス職員」は SCP の用語をそのまま引いた言葉**で、ここから
「異常存在」「収容違反」のような語彙を作らない。ユーザーが言ったのは
**怪異調査員 / 呪われた壁 / 隔離**の 3 語だけ。

## 0003  2026-08-10  外から見た封印の箱

出したもの: R001 の実機の絵 3 枚（段 0 の現実 / 段 1 で会場が消えて床だけ残る / 導入の終わり）
＋ 訊いた 1 点「段 0 も最初から閉じますか。既定はこのまま（段 0 は現実）」

言葉:
- 「パススルーの段階で、導入演出のトリガーの位置に入る前、体験者が体験エリア自体の外側にいるときに、
  体験エリア自体を、不気味な感じの黒い箱みたいなので覆ってほしい。」
- 「これはただ黒いだけじゃなくて、ところどころに、添付画像のような模様が描かれた、
  少し不気味で何かが封印されてそうな感じの箱で。」
- 添付画像: **ほぼ黒（わずかに緑がかったオリーブ寄り）の面に、六角形の格子が
  少しだけ明るい線で描かれている**。低コントラストで、地の暗さが主。

棄: 段 0 を黒く閉じること（＝ R001 で訊いた 1 点への答え。**外から箱が見えることが依頼の前提**なので、
    段 0 の現実は残る）
採: 外から見える封印の箱を足した（`SealedBox`。体験エリアの外に居るあいだだけ出て、
    近づくと開いて中へ入れる）

⚠ **「不気味」「封印されてそう」以外の形容をここから作らない。**
呪符・結界・儀式・魔法陣のような語は誰も言っていない。言われたのは
**黒い箱 / ところどころの模様 / 六角形の格子 / 少し不気味 / 何かが封印されてそう**。
