# 体験の現在形

**体験者にいま何が見えるか（実装の事実）と、それを誰が決めたか（根拠）を、起きる順に 1 枚で並べる。**
根拠は `LEDGER.md` の番号か「未判定（シュビーの実装判断）」。**未判定の行が、次に訊くべき所の一覧になる。**

- 秒数・尺は書かない（`show.json` と実装が正）。書いてある秒数は目安で、食い違ったらコードが正
- 体験者に見えることを変えたら、その行を書き換える（`rules/doc-sync.md`）。日付の節を足さない
- `py -3.11 tools/canon-now.py --check` が、take の過不足・引用の実在・最終確認より新しい判定を検出する
- LEDGER の重複番号（0007・0016・0022〜0029・0075 など）は出現順に `0075a` / `0075b` と書く
- これは**シュビーが実装とログから書いた記述**で、ユーザーの判定ではない（`rules/canon-boundary.md`）

最終確認: LEDGER 0291 / 2026-10-30（0291 の帰還の別れの人形と台車の廃止を 4-A・終幕へ反映）
