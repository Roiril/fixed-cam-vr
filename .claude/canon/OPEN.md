- 既定で進んだら「既定で進行中（日付）」と印を付ける。**黙って既定を使わない**
- 答えが出たら `LEDGER.md` へ逐語で移し、ここから消す

## 案（未判定 — シュビーが出したもの）

⚠ ここに並ぶのは**ユーザーが一度も口にしていない**もの。`LEDGER.md` へは移さない。

- **案 / 2026-08-10 / シュビー — 線は扉である。** 段 0（開始待ち）は会場の現実をそのまま見せ、
  **通過ラインを越えた瞬間に隔離が閉じる**。理由は 3 つ。①段 0 は被せる・誘導する時間なので
  スタッフが見えていないと運用が成立しない ②「歩いて入ってくる動きのまま始まる」という
  既存のライン設計と因果が一致する ③閉じる瞬間が体験の開始そのものになる。
  → R001 で実装した。**ユーザーは「パススルーの段階でも覆う」と言っており、段 0 も含む読みがある。**
- **案 / 2026-08-10 / シュビー — 隔離の閉じ方。** いまは一様なフェード（1.5 秒）。
  候補は「周縁から寄せる」「上（天井）から降りてくる」「床の境界から立ち上がる」。
  頭に追従する閉じ方（周縁）は世界に固定されないので却下気味。
- **案 / 2026-08-10 / シュビー — 黒の質。** いまは純黒。候補は「ごく薄い固定パターンの粒を乗せて
  “面”に見せる」「壁面のようなごく暗いテクスチャ」。純黒は「描画が死んでいる」にも見える。
- **案 / 2026-08-10 / シュビー — 音で調査員だと伝える。** 画面に文字を出せない
  （`rules/show-design.md`「HMD に出す文言の規約」）ので、封鎖音・室内のトーン・無線の呼び出し音が
  文字なしで設定を運べる唯一の帯域。`BgmDirector` が既にあるので素材だけの話。
- **案 / 2026-08-10 / シュビー — カメラの位置に録画ランプ。** 2026-08-01 に棄却された「構造の線」は
  計測器に見えたが、**監視カメラの録画ランプ（小さな赤い点）は世界の中の物**なので別物。
  「どこから見られているか」を文字なしで伝える。
- **案 / 2026-08-12 / シュビー — スクリーンは窓ではなく口である。** 段 4 で現実（＝封印の箱の面）を
  細かなセルに割り、スクリーンの矩形へ吸い込ませた（R006）。**ユーザーが言ったのは
  「ピクセルが細かくセルのように分割されて、割れて粉々になってスクリーンに入っていく」まで**で、
  「スクリーンが現実を飲む口だ」という読みはシュビーが足したもの。終幕（現実へ帰す段）で
  破片が逆に吐き出されて戻る形にすると対になるが、**まだ作っていない**。
- **案 / 2026-08-12 / シュビー — 割れ目を六角にする。** いまは正方の画素格子で、これは
  「カメラが現実を標本に落とす」の語彙。封印の箱と同じ**六角格子**で割ると
  「封印の模様に沿って割れた」になり、意味が世界の側へ寄る。**どちらが良いかは未判定**。
  正方を選んだのは、ユーザーの言葉が「ピクセル」「セル」だったから。
- **案 / 2026-08-12 / シュビー — 破片に現実の絵を載せる。** いまパススルー側の破片は
  「現実が覗く窓」で、中身は動かない（アプリはパススルーの画素を持っていない）。
  Meta の surface-projected passthrough（`OVRPassthroughLayer` に自前メッシュを渡す）なら
  **破片が現実の絵を持って飛ぶ**可能性がある。**未確認**で、パススルーの初期化を作り替えるため
  今回は入れていない。切り分けは 30 分程度。
- **案 / 2026-08-12 / シュビー — 音の層は「現実」と「装置」の 2 つだけ。劇伴を足さない。**
  この体験の恐怖は「装置は正直に映している」という信頼の上に乗っている（3 周目の反転が成立するのは
  それまで装置が嘘をつかなかったから）。劇伴は「作者がいま怖いと言っている」という**外部の声**なので、
  同じものを音で壊す。`rules/streaming.md` が選択的彩度や 1 フレームの顔を禁じているのと同じ理屈。
  → 実装した（`rules/sound-design.md`）。**ただし既存の `HorrBGM.mp3` は外していない** —
  ユーザーが選んだ音源を外すのは世界観の判定なので、代わりに節目のたびに退く（duck）ようにした。
- **問 / 2026-08-12 / シュビー — `HorrBGM.mp3`（劇伴）を残すか。**
  いまはラン全体に流れている。上の案を突き詰めるなら外す番だが、**外すのは判定**。
  既定: **残す**（節目で退く形のまま）。聴いてから決めてよい。
- **案 / 2026-08-12 / シュビー — 山の直前に無音を置く。**
  通しの絵（`logs/sound/preview_intro.png`）を見ると、地の音が最初から最後まで途切れない。
  和ホラーは無音を使うので、破砕の直前に 0.5 秒ほど地を引くと事件が立つ。
  **いまは同時に引いているだけ**（`SpotBedDuck`）で、事前の「息継ぎ」は入れていない。
  段 3 の終わりに引くのが実装上いちばん素直。**聴いてもらうまで判定できない**ので保留。
- **案 / 2026-08-12 / シュビー — 封印の箱の唸りを、近づくほど大きくする。**
  いまは 3D 音源として箱の中心に置いてあるので距離で自然に大きくなるが、
  「近づくと始まる」（LEDGER 0005）という約束を音でも先出しできる。
  距離に応じて唸りの**うねりを速くする**と「気づかれた」に読める。未実装。
- **案 / 2026-08-12 / シュビー — 3 周目に装置の声だけが残る。**
  周回で装置が痩せる（LEDGER 0012）のに対して、**部屋のトーンも一緒に痩せさせる**と
  「現実の側が先に消えていく」になる。いまは部屋は本編を通して一定。未実装で、
  やるなら「落とすのは解像度だけ」（LEDGER 0012 の ⚠）に触れるので判定が要る。
- **案 / 2026-08-10 / シュビー — 隔離が破れる。** 3 周目に隔離殻の一部が欠けて会場が覗く、
  あるいは黒の中に「そこに無いはずの面」が増える。隔離は一度成立させると破る演出が使える。
