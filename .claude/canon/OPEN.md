# まだ聞いていないこと / シュビーの案

**2 つを分けて置く。混ぜると、案が判定に化ける。**

- **問** — ユーザーしか持たない事実。既定を添えて置き、返事が無ければ既定で進む
- **案** — シュビーが出した世界観・演出の案。**未判定**。ここに置いてよいが、
  `LEDGER.md` へは**ユーザーが口にしたときだけ**移る

書き方の規律:

- 1 行 1 問。**既定を必ず書く**（既定が無い問は、返事待ちで作業を止める＝許可要求と同じもの）
- 訊くのは**1 度に 1 点だけ**（`skills/direction-round`）。ここに 5 個あっても、出すのは 1 個
- 既定で進んだら「既定で進行中（日付）」と印を付ける。**黙って既定を使わない**
- 答えが出たら `LEDGER.md` へ逐語で移し、ここから消す

### まだ直していない設計の穴（2026-08-15・Codex の監査 6 件のうち残り 3 件）

⚠ **どれも「いまの手順では表面化しないが、順番が変わると壊れる」型。** 直した 3 件
（現地リセットで卓の占有が残る / APK を焼き直してもキャッシュが優先される / 音のラッチが 2 人目で落ちない）
は `ROUNDS.md` の R023 にある。

- **体験中にコース（`layout.course.order`）を変えると、周回だけが 1 周目へ戻る。**
  `LapCounterLogic.SetOrder` が位置と周回をリセットする一方、演出の once 履歴・経過時間・録画の世代・
  BGM はそのまま。⇒ **3 周歩いても終幕へ入らず、時間切れまで続く**ことがある。
  起きる手順: 体験者が歩いている最中に、スタッフが卓で床の塗りやコース順を保存する（リハーサル中は普通に起きる）。
  直す方向: **layout / course の変更は次の体験者まで保留する**（即時反映するなら周回だけでなく
  run・timeline・take・録画・BGM を巻き込んだ全リセットにする）。
- **「タイムラインを全部消す」がオフライン再起動で復活する。** ライブ受信は
  「rev があって segments が空」を意図的な全削除として受けるのに、**キャッシュ読込は

- 音: 一気に出るので打鍵音は無し。塗り替わりの頭で乱れの音（`sfx_glitch`・既存の 3 種を順に）を 1 発
- 嘘の一文も同じ形。旧「引き延ばし → 抵抗 → 崩壊」の弧は廃止（初見には装置の不調にしか見えない）。
  嘘を言った後に面が消えたままになる仕様も廃止 — 塗り替わった面を保持して普通に閉じる。嘘は 1 回だけという門は残す
- 「止まってください！」以降と呪いが解けた後は従来どおり斑 0・打鍵で出す
- 見送り: 前線を斜めにする／前線の縁を光らせる（明るい矩形は出さない・0131）／読ませる時間を報告ボタンで延ばす（報告を進行に使わない）

### 連絡の面の呪い — 塗り替えは、本編の乱れをまねた「連絡の面用の乱れ」で（0231）

案 / 2026-09-18 / シュビー（0231 を受けて。見え方の採否は未判定）。
設計批評（design-critic 1 体）は「部分採用」で、以下はその指摘を取り込んだ後の形。

- 本編の乱れ（`_Glitch`）から採るのは 3 つ: **帯ごとの横飛び**・**帯ごとの脱落**・**全体の明滅**。
  組み替わる速さも本編と同じ（飛び 18Hz・脱落と明滅 42Hz）。立つ帯の選び方（確率）も本編と同じ式
- 連絡の面用に変えるところ:
  - 帯は面の上端から **4cm**（本文 1 行ぶん）で割り、最大 8 本。本編は枠の 1/24 だが、細かくすると字が帯で割れて文字と地の層が食い違う
  - **前線も同じ帯に乗せる。** 帯が 1 本ずつ一斉に反転する（0230 の「列ごとの段」はやめた。
    CPU の文字と GPU の地で前線がずれると字が途中で割れる）
  - 飛ぶ幅は片側 6cm（全幅の ±6.3%・見かけ 1.7° ＝ 字 1.4 個ぶん）。本編は枠幅の ±11%
  - 脱落は**灰の砂を混ぜず、消す**（明るさは上げない）。黒い地と象牙の字の面で砂を混ぜると明るい矩形が出る（0131）。深さは本編と同じ 0.5 まで
  - 明滅は面全体の不透明度に掛ける（0.78〜1）。明るくはしない
  - 帯の外へ飛んだ字は面の矩形で切る（本編は黒い枠に落ちるが、ここは背景がパススルーなので字が宙に浮く）
  - 面の枠そのものは動かない。動くのは中身（字・顔・地の模様）だけ
- 強さと尺: 頭打ち **0.6**（本編と同じ・0057）。前線の頭で 0.06 秒で立ち、降りているあいだ（0.45 秒）は頭打ち、
  抜けてから **0.12 秒の尾**を引いて呪われた面へ落ち着く。読ませているあいだは 0
- 帯ごとの値は C# が 1 か所で作り、地・ステンシル・顔・文字の 4 つへ同じ値を配る（HLSL 側で別に乱数を引かない ＝ 層が同じ帯で同じだけ飛ぶ）
- 問（既定つき）:
  - 降りている 0.45 秒のあいだ字が読めなくてよいか → 既定: よい（読ませた後に壊す順序なので、壊れている最中に読める必要は無い）
  - 塗り替わった後に弱い乱れを残すか → 既定: 残さない（0.12 秒の尾で止める。残すと「壊れた装置」に寄り、「呪われた双子」から離れる）
  - 0.75 の「読ませる」段に 0229 の 55% の斑を見せるか → 既定: 見せない（0230 の芯は「通常の面が先に丸ごと見える」）
- 見送り: 縦の同期ずれ（本編にはある。帯 1.6° の面では 3% は読めない）／読ませている最中の弱い前触れ（before が壊れる）

### 嘘の一文 — 正常の面は異常を検知し、塗り替えられた行が「検出しませんでした」に書き換わる（0232）

案 / 2026-09-18 / シュビー（0232 を受けて。見え方の採否は未判定）。
設計批評（design-critic 1 体）は「部分採用」で、以下はその指摘（嘘の文面・描き方・色・0.75 以上の返事）を取り込んだ後の形。

- **読ませる段の文面 = 当たりの報告の返事そのもの**（ja「異常を検出しました」/ en「An anomaly was detected.」/ fr「Anomalie détectée.」）。
  初見の人が 1〜2 周目に見た返事と同じ字面が、目の前で書き換わる。スケッチの「異常が検出されました。」ではなく既存の文を使う
- **塗り替えられた行の文面 = その真実の最小編集**（ja「異常を検出し**ませんでした**」/ en「An anomaly was **not** detected.」/
  fr「Anomalie **non** détectée.」）。頭が同じで尾だけ変わるので、2 秒で尾だけ追えば「書き換えられた」と読める。
  ⚠ 既存の「異状は検出されませんでした」（何も無い所で報告したときの正直な返事）は流用しない —
  1〜2 周目に既出の字面なので、嘘に見えない。新しい字は無い（フォントの焼き直し不要）
- **描き方**: 第 2 の面は作らず、本文と同じ TMP で、**前線がその行の帯を越えたコマに文字列ごと差し替える**。
  差し替えた後は字の切断を止め（画素の切断は前線が渡り切っているので要らない）、乱れ（帯の飛び・脱落・明滅）はそのまま掛かる。
  ステンシルを反転させて嘘を「呪われた画素にだけ」描く案は捨てた — ステンシルの無い形式で嘘が 1 画素も出ない側へ倒れる
- **色は象牙**（本文と同じ）。朱赤は黒の地で輝度が低く、110 画素・2 秒・乱れの下で読み切れない公算が高い。
  「嘘は赤」の規則（0229 のシュビーの案）は、面全体が呪われて見える段では役目を終えている。**嘘を言うのは装置の声**
  （人形の走り書きではなく、乗っ取られた装置が平然と報告する方が冷たい）
- **走り書きは嘘の行の両端に残す**（スケッチの「～異常を検出しませんでした～」）。差し替えた後、その行の走り書きの矩形を
  字の左右の余白（本文の列の全幅から字の実寸を除いた所）へ置き換える。上下の「～～～」行はスケッチの比喩と読み、足さない
  （面の高さは行数で決まり、3 行にすると読ませる段が空行の間延びした面になる。縁の毛羽立ちを波線の代わりとも言わない）
- **侵食度 0.75 以上では、装置は「異常なし」に当たる返事を出さない。** 何も無い所で報告したときは、判定を持たない一文
  「装置が解析しています」/ en「Analyzing.」/ fr「Analyse en cours.」（`CommsNotice.MarkAnalyzing`）を出して走り書きに消える。
  「異常なし」は人形に乗っ取られた結果（0232）なので、乗っ取られた装置が正直に「異常なし」と言う経路を閉じる
- 嘘は 1 回だけのまま（0232 は「なぜ異常なしと言うか」で、頻度の話ではない）。その後の当たりの報告は真実の返事が出て走り書きに消える
- 問（既定つき）: スケッチの「走り書き／嘘／走り書き」の 3 段は形の比喩か、満たすべき指定か → 既定: 比喩（中段だけ）
