# 判定の傾向（シュビーの読み）

**ここに書いてあるのはシュビーの読み。ユーザーの判定ではない。** 判定の正本は `LEDGER.md`。

場面をまたいで繰り返し出た判定だけを、**否定と肯定の逐語を対にして**並べる。
語の出現数で作らない。同じ語が逆向きに使われることがある（「デジタル」は 0230 ではユーザー自身の案）。

## 使い方と拘束力

- **出す前の自己点検だけに使う。** 各項目の「出す前に自分へ向ける問い」を、見せる前に通す
- **依頼を字義どおりに作らない理由に使わない。** 傾向と依頼がぶつかったら、字義どおりの版を作り、
  傾向に寄せた版を**並べて**出す（`skills/direction-round`）
- 足す条件は 2 つ。**別々の場面で 2 回以上**出たこと。**肯定の側の逐語も付けられる**こと
  （否定だけ並べると「避けるもの」の一覧になり、何を作ればいいかが消える）
- 新しい判定が項目と食い違ったら、項目を書き換えずに「矛盾」へ並べる

## 1. 「チープ」— 式や格子で作った、規則的で平坦な見た目

否定（逐語）:
- 0018「チープだし、わざと加工してる感というか、現実でこんな感じで粗くなることはないだろう感がある。」
- 0075（08-17・2 件目）「なんか急にチープになった。」
- 0180「現状は良いけど、チープ。デザイナー目線で考えて。」
- 0207「エージェントのスクリーンのデザインと文字が出る演出、荒削りでチープである。」
- 0238「整然としすぎているし、目の質感とかデジタル感とかが参考画像にくらべとてもチープである。ほんとうに参考画像を真似して。」
- 0016（08-12・2 件目・音）「チープな電子音はチープすぎるからやめてほしい」

肯定（逐語）:
- 0075（同）「スイの表示のような絵柄で、黒と輪郭の白のバランスとかもスイを参考に、いい感じにしてほしい」
- 0180「私はAがいい」（Codex に照明だけ描き直させた版）
- 0239「閉じる開く、目玉ぎょろぎょろ、などの表現を、もっと整合性高く(破綻なしで)できれば完成で。」（Codex に描かせた版の目。質感は通った）

シュビーの読み: 否定されたのは、手続き（式・均等な格子・単純なフィルタ）で作った規則的で平坦な絵。
通ったのは、参照（スイの絵柄・参考画像・生成 AI に描かせた版）に寄せて作った回。2〜3 例からの読み。

出す前に自分へ向ける問い:
- この見た目は式で作ったか、参照から作ったか。**参照と並べて見たか**
- 現実（またはその参照の世界）で、こう見えることがあるか
- 整いすぎていないか（等間隔・等サイズ・同じ向き）

## 2. 「デジタル」— 平板な質感は否定、乗っ取りの動きは本人の案

否定（逐語）:
- 0011「体験スペースを最初に覆っている黒い箱のテクスチャだけど、シンプルデジタルチックなのっぺりとした」
- 0238「目の質感とかデジタル感とかが参考画像にくらべとてもチープである。」
- 0285「急にデジタル感が強すぎてあまり世界観にマッチしていないきがする。」「のっぺりしているのが原因かもしれない」

肯定（逐語）:
- 0230（ユーザーの案）「スイの文章を全部見せた後に上からデジタルが侵食されるようなアニメーションで急に塗り替わるという感じ」
- 0235「もっとSFチックな、幻想的な美しい感じにしたくて」

矛盾: 「デジタルを避ける」と読むと 0230 を覆す。

シュビーの読み: 否定されているのは、デジタルの**質感が平板**（のっぺり）で、隣の場面から浮くとき。
デジタルな出来事（侵食・乗っ取り）そのものは否定されていない。

出す前に自分へ向ける問い:
- 面がのっぺりしていないか（質感・奥行き・光のむら）
- **隣の場面と並べて**、そこだけ別の作品に見えないか

## 3. 「美しい」— 壊れや異常も、すごさより美しさで見せる

否定（逐語）:
- 0207「パススルー→2Dの演出、すごくはあるが美しくはない。」
- 0222「割れ方、割れた破片の見た目全部みても、まだ芸術、アート、美しいとは言えない。」
- 0212「参考画像は派手すぎるけど、割れ方とか動き方とかはこれをイメージしてほしい」

肯定（逐語）:
- 0207「美しいがバグっていることが直感的にわかる。が理想。」
- 0004「幾何学的にきれいな、細めの線にして、また動的に光が模様に沿って」
- 0235「割れた瞬間に、破片と一緒に光の粒みたいなのも飛ばして、それの反射光できらきらさせることで美しくSF的にならないだろうか。」

シュビーの読み: 壊れ・乱れ・乗っ取りを描くときも、美しさが先に来る。派手さ・量は加点にならない。

出す前に自分へ向ける問い:
- 壊れていることを描いた結果、**絵そのものが壊れて**いないか
- 量や強さで押していないか（減らしても伝わるか）

## 4. 「AIっぽい」— 汎用の型を避け、映画・作品を参照する

否定（逐語）:
- 0248「配置やフォントや配色などのデザインがAIっぽいので映画っぽくして」

肯定（逐語）:
- 0180「廻り視のキービジュアルを、もっとクオリティ高く、映画のキービジュアルのようにしたい。」
- 0188「デトロイトビカムヒューマン風にしてほしい。ただ、完全パクリではなくうまく廻り視の世界観に落とし込んだような雰囲気に。」

シュビーの読み: 均等な配置・既定の書体・無難な配色という汎用の型が「AIっぽい」。
映画のタイトルやゲームの UI を参照し、そのまま写さずこの作品の世界観へ落とす。否定の逐語は 1 件だけなので、
項目としては弱い（肯定側が 2 場面にまたがるので残した）。

出す前に自分へ向ける問い:
- 参照にした映画・作品を 1 つ名指せるか
- 配置・書体・配色のどれかが既定値のままになっていないか
