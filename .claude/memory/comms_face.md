# AIエージェントの顔（連絡の面の左に立つ角丸の枠）

制定 2026-08-17（`canon/LEDGER.md` 0071）。世界観の判定は LEDGER、体験の骨格は
`rules/show-design.md`「AIエージェントには顔がある」が正本。**ここは焼く側の罠だけ**。

**版は 2 枚**（2026-08-17・0073）。スイと、**侵食の行き先の市松人形**。

| | スイ | 市松人形 |
|---|---|---|
| 素材 | paperdoll の `chara/out/sui/expression.png` の 1 枚目 | **実物の写真から Codex に起こさせた線画** |
| ここに置いてある切り抜き | `tools/comms-face/sui-neutral.png` | `tools/comms-face/doll-lineart.png` |
| 出る | `Assets/Resources/Comms/SuiFace.png` | `DollFace.png` |

焼くのは `py -3.11 tools/make-comms-face.py --parts`（`--only sui|doll` で片方）。
どちらも 256 角・RGB は白・**A だけが墨**。検分は `logs/comms-face/parts.png`
（1 行が 1 枚 ＝ 素材 / 外形 / 区画 / 線 / 墨 / 焼き上がり / 110 画素）。

## ⚠⚠ 人形は写真からは焼けない（2 通り試して駄目だった）

| 試したもの | 何が起きたか |
|---|---|
| **正本の写真**（`plate_front.jpg`） | 背景も髪も暗くて**外形が取れない**（実測: 背景 L=26〜52 / 髪 L=27） |
| **明るい地に立つ資料の板**（`gen_standing.png`） | 外形は取れるが、**写実には彫るべき線が無い** |

2 つ目が本質。スイは元が線画なので暗い所を彫れば髪の束も睫毛も出るが、写実は**線が 1 本も無い**。
髪と顔の境目を自分で引いて補ってみたが、線が 1 本しか無いので出たのは
**丸い頭に丸い顔が浮いているだけ**の絵で、人形だと分からなかった
（2026-08-17 のユーザー赤入れ「今はなんか変」）。

⇒ **実物の写真を参照に、Codex へ閉じた線画を描かせる**（依頼の作法は `tools/doll-ref/PROMPT.md`）。
線画なら**スイと同じ形の素材**になるので、同じ規則がそのまま効く。
違うのは外形の取り方だけ — スイは色の差、人形は**線で囲まれた内側を塗りつぶす**。

⚠⚠ **線は閉じさせる。** 1 画素でも途切れると塗りが外へ漏れて絵が丸ごと壊れる。
プロンプトに「後段のプログラムが塗りつぶす」ことまで書くと通った。
⚠ **描くものを番号で列挙して、それ以外を足させない。** 書かないと髪の毛流れや影が入り、
彫ったときに顔が線だらけになる。
⚠ 線画は**資料であって正本ではない** — 正本はいまも写真（[[doll_reference_kit]]）。

## ⚠⚠ 侵食は溶暗ではなく斑

2 通り焼いて比べた。**混ぜる（クロスフェード）と alpha が中間の灰へ落ちて、
「侵されている」ではなく「薄くなっている」**に見える。斑（値ノイズの閾値）なら
どの画素も必ずどちらかの顔で、境目だけが柔らかい。

⚠ 斑は **uv だけで決まる**（実行時に乱数を振らない）。ちらつかせると侵食ではなくノイズに見える。
⚠ **2 枚は同じ規則で収める**（`compose`）。大きさや座りがずれると「入れ替わり」に見える。

## ⚠⚠ 明暗が逆なので「肌を塗らない」と顔が消える

ユーザー指定は「輪郭だけ抽出し、髪は輪郭と同じ色で塗りつぶし、背景はない感じ」。
参考のスクショは**白い紙に青い墨**で、肌は紙の色（＝ 塗らない）。

**この面は暗い地に明るい墨なので、明暗がまるごと逆。** 素直に「髪だけ塗る」と、
**髪が明るく肌が暗い陰画**になり、目も口も読めない黒い穴が顔の位置に空く。
しかもスイは**白銀の髪**なので、髪と肌と背景の明るさがほとんど同じ（実測 217 / 231 / 245）で、
領域を分ける手掛かりが**赤み（R−B。肌 +16 / 髪 ±4）しか無い**。

塗り分ける方向を 6 通り試して全部失敗した（髪だけ塗る／顔の輪郭を凸包で抜く／目を実体で塗る／
目のまわりに紙の隙間を空ける／瞳を punch out する／前髪を線にする）。共通の失敗は
**明るい髪と明るい目が隣り合って溶ける**こと。

⇒ **頭の外形を全部塗って、元の絵の線を彫る。** 元絵は「明るい面に暗い線」なので、
彫れば「明るい墨に暗い地の線」になり、**関係がそのまま保存される**。髪の分け目も睫毛も
鼻も口も、描かれたとおりの形で残る。判定は明るさの閾値 1 つ（`LINE_MAX_L = 168`）だけ。

## ⚠ 実機では 110 画素しかない

枠は 1.5m 先の 0.15m 角 ＝ 見かけ 5.7°、Quest 3 は視野中心でおよそ 20 画素/度。

- **線は必ず太らせる**（`LINE_W`）。細いまま焼くと縮小で溶けて灰色の靄になる
- **閾値を上げて線を増やすのも同じ理由で駄目**。195 まで上げると髪の束が全部ばらけて糸くずに見える
- **目だけは別の閾値**（`EYE_LINE_MAX_L`）と**別の太さ**（`EYE_LINE_W`）。瞳は青くて明るい
  （実測 159）ので、全体と同じ 168 では睫毛の 1 本線しか彫れない。
  ⚠ 全体を上げてはいけない ＝ **目の周りに限る**（睫毛の塊を 2 つ拾って広げる）
- ⚠⚠ **目は上げすぎると怖くなる**（2026-08-17 の赤入れ・`canon/LEDGER.md` 0072）。
  200 だと瞳と睫毛と下瞼が 1 つの黒い塊になり、**目ではなく落ち窪んだ眼窩**に見える。
  **175 ＋ 太さ 1** が持ち場。太さを髪と同じ 2 にすると、目が隣の線と繋がってまた塊になる
- **外形の縁は線に食わせない**（`RIM_KEEP`）。食わせると睫毛や髪の分け目が輪郭まで届いた所で
  頭の縁が欠け、縮めたときに「輪郭が途切れた頭」になる
- 縮小は**面積平均**（`INTER_AREA`）で 4 倍から落とす。ここが縁のなめらかさの全部

## ⚠ 顎の下の影は「目」と同じくらい暗い

`L < 115` で目の芯を拾うとき、**外形の上から 72% までに限らないと顎の影を掴む**
（実測で面積 2628 の巨大な塊になり、凸包が顔の下半分を覆った）。`EYE_ZONE_TOP` がその線。

## 面の側の罠

- **顔のぶんは面を左へ伸ばす**（文面は 1mm も動かさない）。`SetFrame` は**左端を引数で受け取る** —
  `-fullW/2` を左端と決め打ちしていた頃の式のままだと、顔のぶん面が右へずれる
- **面の丈に下限ができた**（枠が縦にはみ出さないため）。0065 の「出ている帯だけを覆う」に
  反しない — あれが禁じたのは中身の無い空の箱
- **`FixedCamVr/CommsAvatar` は `Shader.Find` で引く**ので Always Included に入れてある。
  外すと Editor では出て**実機だけ剥がれる**（`Unlit/Color` と同じ穴 — `rules/unity-vr.md`）
- 観測は `ev=sum` の **`commsFace=<枠>/<版>/<濃さ>`**。**3 つとも別の壊れ方**なので畳まない
