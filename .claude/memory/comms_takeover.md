# 出力中の報告を奪う演出

2026-09-14。ユーザーは「何かがおかしい。そしてシステムが嘘をついている」と直感できる演出を依頼した。
「装置は正直に映している」を理由に報告文の意味改変を禁じていた旧方針は、この依頼で変更された。
初版への判定は「人形がなぜか2回喋っている」。追記依頼は「進行中の一つの処理が途中から抗えない力によって乗っ取られていく」。
以下の秒数と見せ方は追記依頼への実装案。体験者による判定は未実施。

## 表示

報告文は一つだけ。文字列の差し替えと全文完成後の保持を廃止した。
日本語は「異常なしと判定しました」。英語は「No anomaly was detected.」。
フランス語は「Aucune anomalie n’a été / détectée.」。否定が文頭で分かる一文にする。
日本語の「異常なし」だけを赤くする。英語とフランス語も同じ意味の文頭だけを赤くする。
侵食度1未満では、異常演出の表示中に報告すると「異常を検出しました」と返す。
演出を消せるかは `dismissible` が別に決める。

2026-09-14の追加依頼で見せ方を再設計した。以下の演出はエージェントによる実装案。
出力尺Tは日本語で2.20秒。原文の配置と改行を保ち、既に出た字から縦へ引き延ばして細くする。
横の消去線は廃止する。消える前に字形が変わる時間を設ける。
人形の顔と仕切りにも同じ向きの変形を進める。別の顔への置換と時間乱数は使わない。
進み.74〜.82では生成と変形を止める。日本語では0.176秒。
その後も出力は再開するが、侵食が加速し、最終文字を出す前に止まる。
パネルの背景も終盤に薄れ、捕捉後は空の黒箱を残さない。
予約済みの打鍵にもStopAllを掛ける。捕捉後の0.35秒は表示を戻さない。
打鍵は新しい文字の出力と対応する。音だけの追加打鍵や二つ目の発話は出さない。
読み上げ音声は元の実装に存在しない。既存の打鍵を出力の停止と再開へ追従させる。

## 進行

侵食度は `CommsInvasionLogic` が表示イベントから決める。1-A〜2-Bは0。
2-Cの単発人形視点 `pov_0` が表示された縁で0.25。続く列の `pov_1` が表示された縁で0.75。
3-Aで体験者位置の人形が実際に表示された縁で1。ランリセットまで保持する。
4-Aの「止まってください！」以降だけは描画の欠けを外し、警告を読める状態にする。
値は逆走で下げない。同じイベントの多重観測でも変わらない。
侵食度1から0.6秒後に一度だけ自動提示する。報告が先に来ればそこで提示する。
侵食中の再報告と長押しでは演出を最初からやり直さない。
「止まってください！」と続く警告は侵食度1でも欠けさせずに読める状態で出す。
中止と次のランには、前回の改変状態を持ち越さない。
