# 出力中の報告を奪う演出

2026-09-14。ユーザーは「何かがおかしい。そしてシステムが嘘をついている」と直感できる演出を依頼した。
「装置は正直に映している」を理由に報告文の意味改変を禁じていた旧方針は、この依頼で変更された。
初版への判定は「人形がなぜか2回喋っている」。追記依頼は「進行中の一つの処理が途中から抗えない力によって乗っ取られていく」。
以下の秒数と見せ方は追記依頼への実装案。体験者による判定は未実施。

## 表示

報告文は一つだけ。文字列の差し替えと全文完成後の保持を廃止した。
日本語は「異状なしと判定しました」。英語は「No anomaly was detected.」。
フランス語は「Aucune anomalie n’a été / détectée.」。否定が文頭で分かる一文にする。
通常の空振り報告の文言は変えない。

仮想の出力尺Tは文字数と既存の言語別速度から求める。下限1.25秒。上限2.2秒。
印字開始から0.35Tで文頭の侵食が始まる。元の印字も続くが速度は徐々に約70%へ落ちる。
侵食は微速から三乗で加速する。Tで印字へ追いつく。出力は原文の約86%で止まる。
空白と改行を含む字順で進める。二行目を一行目より先に消さない。
文字は行の中央へ潰れて消える。罫線が同じ順序で追う。字の配置は組み直さない。

追い付く0.18秒前から仕切りを縮める。顔は形を変えず口元から版を消す。
追い付いた瞬間に文字と打鍵を止める。予約済みの打鍵にもStopAllを掛ける。
空の黒い面を0.35秒残した後に退場する。二つ目の発話や結果文は出さない。
新しい警告音や人声は足さない。既存の黒い面と象牙色の印字を使う。

## 進行

最終通常周で人形置換の異変が表示されたことを確認する。
表示から0.6秒後に一度だけ自動提示する。報告が先に来ればそこで提示する。
単なる解除失敗を異変の検出と扱わない。報告時の実際の表示状態を保存して判定する。
侵食中の未解決報告と長押しでは演出を最初からやり直さない。
捕捉後の未解決報告にも返答しない。成功報告を除き復路まで復活させない。

帰りの区間では改変を止める。エージェントが持ち直して警告する既存の流れを保つ。
成功報告は優先する。解除後の顔と文字は既存のReleaseKで正常へ戻る。
中止と次のランには、前回の改変状態を持ち越さない。

## 通常時の侵食

0.22秒ごとに欠ける文字が入れ替わる表現を廃止する。
同じ箇所の欠けと滲みが侵食量に応じて増える。侵食量が一定なら絵も止まる。
帰りの区間で0.12まで持ち直し、解除後に0へ戻る既存の変化は維持する。

## 検証

`CommsPreview.RunTakeover` はUnityの実描画を連番と計測値へ出す。
呼び出しは `tools/unity.ps1 menu raw:FixedCamVr.Streaming.EditorTools.CommsPreview.RunTakeover`。
その後 `py -3.11 tools/render-comms-takeover-preview.py` で3言語の音付き動画と画素検査を作る。
出力は `Logs/comms-takeover-20260914/`。既存の出力を削除せず日時別に保存する。
原文の生成と消去が重なる時間を画像で確認する。
捕捉後は実際の字形と顔が消えているかを確認する。
打鍵数は原文全体ではなく、捕捉前に生成する可視字数と比較する。
初回表示と再報告を区別する。無入力と中断と次のランもテストする。
実機の視野内で読む時間と怖さは、Editorの描画だけでは判定しない。

追跡演出の実描画では日本語90コマ。英語93コマ。フランス語108コマ。
打鍵数と生成する可視字数はそれぞれ10/10・18/18・25/25。捕捉後の打鍵は0発。
消えた字と表示中の字が共存する時間は0.43秒・0.57秒・0.83秒。
その間に新たに3発・7発・10発の打鍵が出る。全文は一度も完成しない。
空の面の保持中に比較した2コマの画素差は0。本文の位置は動かない。
動画は実描画へ既存の音素材を合成したもの。打鍵の発火時刻は実測値を使う。
実機の立体音響と音量変動は再現していない。
EditModeテストは1,885件通過。失敗と除外は0。描画ログの解析テストは7件通過。
`menu text-audit`は日本語・英語・フランス語で合格。
Quest実機と体験者による判定は未実施。

テレメトリは `ev=commsTakeover` に段の変化を保存する。
`erase`と`reveal`は消去と生成。`collapse`は顔と仕切りが失われる進み。
`cx`は実際に欠けた字数。`glyph`は本文の濃さ。`faceInk`は顔の濃さ。
`cut`は打鍵を停止した累計。開始と完了の累計も保存する。
`analyze-xp-log.py`は未完成の報告が消え、打鍵停止が実行され、顔が戻らないかを確認する。
段が変わっただけでは描画成功と判定しない。
