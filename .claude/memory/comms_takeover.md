## 形

侵食度 0.75 以降に届く連絡（実際には報告の返事②と、3 周目 A の嘘「異常なしと判定しました」）は
**`CommsDelivery.Possessed`**（憑依の出し方）:

| 段 | 尺 | 何 |
|---|---|---|
| 出る | 0.12s | 全文がふっと出る（打鍵なし・`reveal = 1`・濃さだけ上がる） |
| 読ませる | 0.9 ＋ 打つ尺 × 0.45（1.0〜2.4s） | 通常の面そのもの（斑 0・顔はスイ）。嘘は「異常なし」が赤い |
| 塗り替わる | 0.45s | 上端から前線が**帯ごと**降り、上側が呪われた双子（人形の顔・走り書き・毛羽立った地）。**面全体が乱れる**（帯の横飛び・脱落・明滅・0231）。頭で乱れの音 1 発 |
| 尾 | 0.12s | 塗り替わり切った後も乱れだけが残って引く（前線が抜けた瞬間に乱れも消すと「装置が直った」に見える） |
| 呪われたまま | 2.0s（HoldSec） | 全面が双子（0.75 でも 1 でも Max）。そのまま引く |

- 時計は `CommsPossessionLogic`（純ロジック・段の縁は「ぴったり」と「1 コマ手前」でテスト）
- 前線は**帯に吸着する**（`CommsCurseLogic.SweepBandCount` / `SweepBandOf` / `IsSwept` と `CommsCurse.hlsl` の
  `CommsBandOf` / `CurseSweepK`・同じ式）。面を上端から 4cm（本文 1 行ぶん）の帯に割り、進み × 帯数 を切り捨てた本数が
  上から反転する ＝ 進み 0 で 1 画素も呪われず、1 で全面。⚠ 0230 の初版は列ごとの段（1.8cm ＋ ±10% のずれ）だったが、
  CPU の文字と GPU の地で前線がずれると字が途中で割れるので、批評を受けて帯へ替えた（前線の直上の象牙の粒も無くした）
- 顔・地・文字のステンシルは **同じ `_Sweep`（進み・上端・下端）** を読む。斑（`_Curse`）とは `max` で合流するので、
  塗り替わった後に `_Curse = 1` を書いても絵は変わらない（`CommsPanelLogic.Weights` が塗り替わり後に curse を 1 にする）
- 出し方の決め所は **`CommsCueLogic.DeliveryOf(notice, invasion)` 1 か所**。「止まってください！」（浮かぶ）と
  続く警告（打つ）は侵食度に関わらず従来のまま（0070・エージェントが復帰して助ける段）
- 嘘は **1 回だけ**（`CommsCueLogic._takeoverDelivered`）。出ている最中の再報告は頭へ戻さない（`takeoverPlaying`）。
  出し終えたら次の報告は普通の返事（出し方は憑依のまま）。**旧「嘘の後は面が死んだまま」は捨てた**
  （`takeoverModified` の門ごと削除）

## 乱れ（0231）— 本編の `_Glitch` をまねた「連絡の面用の乱れ」

本編から採ったのは **帯ごとの横飛び・帯ごとの脱落・全体の明滅** と、組み替わる速さ（18Hz / 42Hz）と立つ帯の確率
（`GlitchUv` と同じ式）。連絡の面用に変えたのは 帯 4cm（前線と同じ格子）／飛び ±6cm／脱落は灰の砂を混ぜず
**消す**（黒い地と象牙の字で砂を混ぜると明るい矩形が出る・0131）／明滅は不透明度に掛ける（明るくしない）。
強さは頭打ち 0.6（本編の 0057 と同じ）。前線の頭で 0.06 秒で立ち、降りている 0.45 秒は頭打ち、抜けてから 0.12 秒の尾。

- **帯ごとの値は `CommsCurseLogic.ComputeTear` が 1 か所で作る**（種は面が開いてからの秒・実行時の乱数なし）。
  `CommsPanel.PushTear` が `_Tear`（強さ・明滅）と `_TearShiftA/B` `_TearDropA/B`（float4 × 2 ＝ 帯 8 本）を
  地・ステンシル・顔の 3 材質へ同じ値で書き、本文は `ApplyGlyphMesh` が**行ごと**（行の中心の帯）に同じ値で動かす。
  ⚠ 頂点ごとに帯を引くと、帯の境目が行を横切った字は上と下が別の量だけ動いて**斜体**になる（初回の焼きで踏んだ）。
  本編は画素の帯を切って飛ばすので傾かない。行ごとなら行がまるごと横へ切れて飛ぶ。切断は従来どおり字の中心と両端で読み、
  帯の境目の上側はステンシルが画素で切る（＝ 字の上半分だけが走り書きに変わる、本編と同じ「切れ」の見え方）。
  **HLSL 側に第二の乱数を置かない** — 置くと文字だけ飛んで地が止まる（層が食い違う）
- **面の枠は動かない。動くのは中身だけ。** 地は矩形と帯の判定を `pRaw`（生の座標）で、模様と斑の場を `p`（飛ばした座標）で読む
- **飛んで矩形の外へ出た字は切る**（`CommsCurseStencil.shader` の外側クリップ・`_RectHalf`）。本編は黒い枠へ落ちるが、
  ここは背景がパススルーなので、切らないと字が宙に浮く
- 顔は飛ばした uv が 0..1 の外に出たら描かない（`inRange`）。出したまま sample すると端が伸びる
- 乱れの尾は読ませる段（Hold）へ跨ぐ。`CommsPanelLogic.PossessionSample` が Hold では `DurationFor + _elapsed` で
  時計を繋ぐ（Type の段が終わった瞬間に 0 へ落とすと尾が出ない）
- ⚠⚠ **置換で書き直すときは、消した範囲の外の識別子が生きているか `git show HEAD:` の宣言一覧と突き合わせる。**
  帯への書き直しで `SampleX0` / `_sortedField` / `LevelFor` … の 78 行を丸ごと落とし、コンパイルが落ちた
  （テストは古いアセンブリで 133 件通ったと言った。`unity.ps1 test` の exit 5 だけが手掛かり）
- ⚠ 見送ったもの: 縦の同期ずれ（帯 1.6° の面では 3% は読めない）／読ませている最中の弱い前触れ（before が壊れる）／
  塗り替わった後の残る乱れ（「壊れた装置」に寄る）。**開いた問（`canon/OPEN.md`）**: 降りている 0.45 秒に字が読めなくてよいか
