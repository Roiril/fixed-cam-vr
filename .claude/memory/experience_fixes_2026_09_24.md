# 2026-09-24 体験時の不具合修正

対象は FixedCam。Quest α の録画 `com.roiril.mawarimi-20260924-195702-0.mp4` を参照した。

## 人形が出る時刻と書き出し

`export_build.referenced_cue_ids` が `steps[].overlay2CueId` を拾わず、右半分用の
`plate_A_right` とマスクを未使用として除外していた。主画面用の `cueId` と同様に収集する。
未定義の第2表示用 cue も書き出し時に止める。
3-A の凍結カットには人形指定がなく、後続カットまで 1.2 秒ライブが残っていた。
凍結カットから右半分用 cue と人形を設定する。現場の show.json は git 管理外。

## 導入と最後の報告

- 導入は X / Y の長押し案内を最初に待機表示する。報告練習の成功文の後にスイが名乗る。
- 位置合わせ中は会話を隠し、案内の時計と打鍵を進めない。
- 最後の A は「止まってください！」とスイのお願いを表示するまで報告を受け付けない。
  固定秒数だけでは長い文面の終了を保証できない。全文表示の状態を受付条件にする。
  ロック中は長押しの進捗と振動も止める。解除後も一度離してから押し直す。
- 最後の報告で解除が成立したら、侵食が 1 のままでもスイの通常の異常検出応答を使う。
  通常区間で人形が否定する表示は維持する。

## 位置合わせの再試行

失敗メッセージが長押しの進捗より優先され、再試行を最大 6 秒隠していた。
失敗文は次の A 押下まで残し、その押下で進捗へ切り替える。
確認画面でのやり直し A は、同じ押下で点 1 の記録も始める。
位置合わせの終了と再入場では前回の失敗文を消す。

## 現実が割れる場面

録画の 13.40 秒では棚と照明が見える。13.70 秒では多くの破片が灰色の面に見える。
中央破片のガラス質感が元写真を 8.5〜13%まで減らしていたため、部屋の形を追いにくかった。
撮影時の UV は維持する。写真の寄与を破断直後 94%、飛行中 70%へ変える。
反射・屈折・縁・光粒・破片の運動・5 秒の尺は維持する。
撮影範囲外の周辺破片は平均色による補完であり、実在の室内模様として扱わない。

`menu intro -Set retention=1` は同じ形状・時刻の変更前後を描画する。
`reality=<画像パス>` を加えると録画から抽出した実景を入力に使える。
`retention-proof.json` は破断前/終了後の不変と飛行中の差を検査する。
同じ平均輝度の左右反転入力を比較し、単に明るくした面を写真の模様と誤認しない。
`DiagnosticRealityRetention=0` は旧写真量との比較用。通常は 1。
`probes=1` は連番 198 コマを作らず、凍結・縁・光粒・ガラスの描画検査だけを行う。

検証結果は本タスクのログに保存する。装着したときの印象は録画と別に判定する。
