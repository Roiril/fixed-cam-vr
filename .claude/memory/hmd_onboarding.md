# HMD 内の導入（接続確認 → 報告練習 → タイトル → 本編）

2026-09-14。注意事項と言語選択とホラー軽減の設定は、装着前にタブレットで完了する。
HMD 内の導入は、左コントローラーと本編の報告操作を確認するためのもの。

## 体験の順序

1. 黒の中でスイが名乗る。
2. 左コントローラーの接続と位置認識を確認する。
3. X か Y を 1 秒長押しして、報告を 1 回練習する。
4. 「報告を受け取りました」を出す。練習中の報告は本編の件数と演出へ渡さない。
5. X / Y が両方とも離れたことを確認してから、題字を自動で出す。
6. 題字は時間で閉じない。X か Y を 0.5 秒以内で押して離すと閉じる。
7. 既存の歩行誘導へ渡す。到着後は既存の破砕と固定視点への遷移を続ける。

報告練習の完了文は「報告を受け取りました」。

## 入力の境界

- 報告は X / Y のみ。トリガーとグリップとスティック押し込みは読まない。
- 長押しは報告。短押しはタイトル開始。タイトル開始は解放時に確定する。
- 段へ入る前から押されていた入力は捨てる。練習成功後も、一度離すまで題字を出さない。
- 練習途中の切断は進捗を捨てる。再接続後に同じ練習をやり直す。
- 練習完了後の切断では完了を保持する。再接続後の新しい短押しを待つ。
- 接続待ちと練習は本編の演出時計に含めない。

## 表示と言語

- タブレットから受け取った日本語 / English / Français を使う。HMD 内で言語を選び直さない。
- 注意書きの `TitleNotice` は HMD 内では出さない。
- 名乗りと報告練習は既存の `CommsPanel` を使う。本編と同じ面とゲージと振動を先に経験させる。
- 本編開始後にスイの名乗りを繰り返さない。
- 到着文は「到着しました。観測を開始します」。練習済みの装置を初めて起動するように聞こえる文を避ける。

## 壊れたとき

- 左が未接続なら接続待ちを表示する。
- 接続済みで位置が取れなければ、コントローラーを少し前へ出す案内を表示する。
- 15 秒解決しなければスタッフへ声をかける案内を足す。時間切れで成功扱いにしない。
- タイトルの実体を組めない場合と、卓から導入を進めた場合の `ForceClose` は残す。

## 触ったら確かめること

- 練習中の報告による `VisitorMarkCount` の増分が 0。
- 長押しを持ち越したタイトル開始が 0。
- 1 回の練習受付に対して完了表示と完了振動が各 1 回。
- 題字が消える前のパススルー露出が 0 フレーム。
- 日本語 / English / Français の文面が連絡面に収まる。
- タイトル後の歩行誘導と破砕演出が 1 回ずつ続く。
