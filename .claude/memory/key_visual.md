# キービジュアルを触る前に

判定は `canon/LEDGER.md` 0126（枠）と 0180（地の照明）。ここは**機械の事実と踏んだ罠**だけ。

## 経路（2026-09-10 から）

```
tools/make-key-visual.py --emit-plate <生画.png>   # ① 4 周目 A の生成素材 → 実機の明るさ → 16:9
Codex -Mode image（docs/key-visual/relight-prompt.txt の「入力画像:」を①へ）  # ② 照明だけ描き直す
tools/make-key-visual.py --ground <②の画>          # ③ 題字と文字を組む → docs/key-visual/mawarimi_key_visual.png
```

②の返り値は `docs/key-visual/ground_relit.png` に置いてある。**Codex の出力は再現できない**ので、
組み直すだけなら③だけ回す。②を回し直すのは地を変えるときだけ。

## 罠

- ⚠⚠ **「暗くしたい所をマスクで落とす」と、切り抜きに見える。** 2026-08-24 の版がチープだった主因
  （人形の外周に灰色のにじみ・壁の黒が均質なベタ・均一な周辺減光）。暗さは**光の不在**で作る。
  Codex に「壁は塗るのではなく光が届かないので見えない」と書くと、壁の平均が 168 → 8 まで落ちた
- ⭐ **「照明だけ変えた」かは Sobel の相関で見る**（`check_relight.py` の型。入力と出力を同じ寸法にして
  勾配の大きさを正規化して相関）。実測: 同じ画 1.0／照明だけの A 0.57・B 0.54／描き直しが混ざった C 0.39。
  **0.5 を切ったら物の位置が動いている**
- ⚠ **Codex は 16:9 の 1920×1080 を渡しても 1672×941 で返す**（4:3 の 640×480 は 1448×1086）。
  1.15 倍の拡大が入る前提で、地の粒は組む側で足す
- ⚠ **「着物の赤は影に沈める」と書いても沈まない。** A では鮮やかな赤の画素が 7.2% → 10.7% に**増えた**。
  赤の彩度はプロンプトでは動かないので、組むときに赤い画素だけ彩度を落とす（`--tame-red`。既定 0.72）。
  これで「視」が画の中でいちばん鮮やかな赤になる（`title_screen.md` §5.1「赤は 1 つだけ」）
- ⚠ **版の G（視）は活字の縁のまま焼かれている。** R（廻リ）はかすれているので、そのまま並べると
  質感が揃わない。組むときに低周波のむらと小さな抜けを G に掛ける（`glyph()`）
- ⚠ **払いの弧（版の A・y ≥ 760）は人形の顔を横切る。** 題字を中心に置くと必ず群れの上に乗る。
  0.3 倍まで落とした。消すなら版ではなく `add_gain` で
- ⚠ **縦書きの句読点は升の右上へ寄せる**（`draw_vertical`）。素の `ImageDraw.text` で 1 字ずつ落とすと
  「。」が升の左下に来て読めない。`ー` は回す必要があるので**キャッチに `ー` を入れない**
- 光源 3 種の実測（同じ地・同じ骨格のプロンプト）: 右上の裸電球 A ／ 床の懐中電灯 B（幕に 21 体の影が立つ。
  画としてはいちばん強いがユーザーは A を採った）／ 真上の蛍光灯 C（人形の平均 13 で顔が消える）。
  同じプロンプトで A を焼き直した A2 は相関 0.589・鮮やかな赤 17.8% で、見た目はほぼ同じ
  （構図の振れは小さい。採ったのはユーザーが見た 1 枚目。B2・B3 は見ていない）

## 文字（位置は `make-key-visual.py` の既定値）

| 何 | 書体 | 位置 |
|---|---|---|
| キャッチ 2 行（縦書き・右の行から） | Yu Mincho Light 29px | 右の行 x=0.088W、上 y=0.075H。いちばん長い行が 12 字で下端は 0.48H |
| `VR固定視点ホラー` | Yu Mincho Light 30px・字間 0.32em | 中央 y=0.902H（`--billing-y`） |
| 役職 ＋ 名前 | 役職 Yu Gothic 17px / 名前 Yu Mincho 28px。**ベースラインで揃える** | 中央 `--billing-y` + 0.064 |

下端の余白は 36px（1080 の 3.3%）。測るのは `(輝度 > 110).sum(axis=1) > 3` の最下行で、
版の目分量ではなく画素で出す。

- ⚠ **役職と名前を同じ大きさで並べると名簿に見える。** 役職は小さく淡く（`draw_billing`）
- ⭐ **下段を置く前に、その帯の地の ばらつきを測る。** 中央の底は左半分が人形なので、
  幅の狭い行ほど着物に乗る。実測: `IVRC2026`（幅 215px）を中央に置いた帯は sd 25、
  いま残っている 2 行は sd 10.3 と 4.4 で静か。乗るなら `--billing-x` で床の光の溜まりへ寄せる
  （2026-09-10 に 1 度 0.625 へ寄せ、その行が消えたので中心へ戻した）
- **文言はどれもユーザーが口にしたもの**（`canon/LEDGER.md` 0180 の赤入れ 1〜4）。
  キャッチ「廻るたびに狂う世界、／あなたは生きて戻れるか。」も改行と句読点まで原文どおり。
  **書体・大きさ・位置だけがシュビーの判断。** 未判定で残っているのは題字の朱の値だけ
  （`canon/OPEN.md`「キービジュアルの文字」）
