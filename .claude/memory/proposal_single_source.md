## 骨格を捨てるわけではない

企画書由来の骨格は**既に実装され、機械が守っている**ので、文書を読み直す必要が無い。

| 骨格 | どこが守っているか |
|---|---|
| 3 区間を 3 周 / 導入を含め 3 分以内 | `show.json` の著作 + `analyze-xp-log.py` の期待値照合 |
| 1 周目に録画して 3 周目の背景に使う | 同上（録画が飛ぶと FAIL で出る） |
| 人形の差し替え・切替に同期・前後に乱れ | 同上（`veil` / `cg` の効果の実在） |
| 100ms を管理する | 遅延計測（絶対 E2E は未計測 — [[glitch_and_latency]]） |

**骨格は機械が守る。人は絵と物語を作る。** これを先に立ててから「読まない」と決めている。

## ⚠ 旧版にしか無い要求（実装しない）

`docs/archive/` の旧企画書は体験構成が別物。**次の 4 つは現行の体験に無い。**
「企画書にあった気がする」で復活させない。

- **しゃがみ・振り向き・着座**
- **空間音響**
- **監視カメラ風 UI**（カメラ番号・タイムスタンプ）
- **90Hz**

`reports/2026-07-29_proposal-vs-implementation.html` は**旧版**との突き合わせなので、
「重い順のギャップ」はもう当てにならない。
