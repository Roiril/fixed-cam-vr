2026-07-29 にユーザーが「新しい企画書を単一の正にして、古い方を参照させないで」と指示。

**正は [docs/proposal/](../../docs/proposal/) だけ**（第 31 回日本 VR 学会大会論文
「廻リ視：固定視点を用いた実世界ホラー体験」。PDF が正本で、README.md はそこから抽出した本文）。

**`docs/archive/` は読まない。** 旧 `docs/ivrc-proposal.md` / `-v2.md` をここへ移し、
各ファイルの冒頭に廃止マークを付けた。体験構成が別物なので、読むと違うものを実装する。

新旧で要求が入れ替わっている。取り違えると実装が丸ごとずれる:

| 新（正） | 旧（廃止） |
|---|---|
| 3 区間を **3 周**・導入を含め **3 分以内**・各周 30 秒 | 線形の 3 シーン |
| 1 周目に**録画**して 3 周目の背景に使う | 無し |
| 人形を怪物へ差し替え・切替に同期・前後に**乱れ** | 無し |
| 100ms を**管理する** | 100ms 以内（目標のみ） |
| — | **しゃがみ・振り向き・着座**（新版に無い） |
| — | **空間音響**（新版に無い） |
| — | **監視カメラ風 UI**（カメラ番号・タイムスタンプ。新版に無い） |
| — | **90Hz**（新版に無い） |

`reports/2026-07-29_proposal-vs-implementation.html` は**旧版**との突き合わせ。
冒頭に古い旨の断りを入れてあるが、「重い順のギャップ」はもう当てにならない。
