封印の箱の**質感と光り方**（`canon/LEDGER.md` 0011）。幾何と巻き方は
[[../rules/show-design]] の「封印の箱」節が正本で、ここは**地と熾**だけを書く。

## 正本は 2 ファイルで対

| 何 | どこ |
|---|---|
| 版を焼く | `tools/make-sealbox-tex.py` → `Assets/Resources/Intro/SealBoxWear.png`（512²・タイル可能） |
| 版を読む | `Assets/Art/Shaders/Intro/SealedBox.shader` |
| 取り込み設定 | `SealBoxWearImporter`（Repeat・ミップ有り・sRGB off・ASTC 6x6） |
| 版を当てる | `SealedBox.ApplyWearTexture(Material)` — **実行時とプレビューが同じ経路を通る** |

チャンネル: **R=酸化のむら / G=研磨目 / B=磨耗 / A=熾の宿り所**。
⚠ **片方だけ直すと沈黙して食い違う。** 版を焼き直したら必ず `menu sealedbox` で絵を開く。

## 罠 5 つ（全部 2026-08-12 に実測で踏んだ）

1. **磨耗を明るい色で「置き換える」と白いカビ・霜に見える。**
   `lerp(surf, _MetalColor*1.5, worn*0.6)` は暗い面の上に淡い塊を作る。
   擦れて出るのは**地金の色が少し強く出るだけで白くならない**し、擦れる方向が決まっているので
   丸い斑にもならない。→ **加算にして研磨目に沿わせる**（`worn * 0.42 * (0.35+0.65*grain)`）。
   版側も高周波へ（14/31/67 セル・上位 2 割）。明るい画素 5.6% → 0.7%
2. **オクターブを重ねたノイズは中心極限で 0.5 付近へ寄る。** 固定しきい値（0.6 等）で切ると
   **何も残らない**（熾が平均 5/255 で全滅した）。`pct_curve` で「面積の何 % を残すか」で書く
3. **版のタイルは周長の約数へ丸める。** 六角と同じ扱い。丸めないと 0006 で噛み合わせた縦 4 辺に
   別の縫い目ができる。**小さすぎても駄目** — 1.35m だと 3m 四方の箱で 9 回回って
   同じ汚れが横に並んで見えた（2.4m ＝ 周長 12m を 5 分割へ）
4. **`hearth²` は面積では埋まらない。** 「面そのものの熾は係数が小さくても面積が広いから勝つ」と
   予測して外した。熾の平均は 17/255 ＝ 0.067 で、2 乗すると 0.0045。
   にじみは線の近くで `halo²` が 1 に達する。**見えているのは溝のまわりのにじみだけ**
5. **稜の擦れを「一様な明るい帯」にしない。** 均等な縁取りは**面取りしたモデル**の顔で、
   かえって新品らしくなる。地のむらと研磨目を掛けて擦れ方を不揃いにする
6. **「細かい細工は遠景で消える」は成り立たない。** 線幅を `aa`（画素あたりの変化量）で
   下から押さえてあるので、溝の壁の陰影も 1 画素は残る。3.6m からでも面が彫られて見えた
7. **減らす手を並べると効きが掛け算になる。** 版の分位・乗数・溝の下駄・`_HotFrac` を
   同時に絞ったら「はっきり赤い」が 2.5% → 0.1%（10 秒で最大 0.35%）＝ 芯が事実上消えた。
   戻すときも 1 つずつ（`_HotFrac` だけ 0.66 → 0.60 へ）
8. **テカらせない = 鏡面項を書かない。** 金属らしさは
   ①研磨目の明暗 ②磨耗から覗く地金 ③斜めから見たときだけ広く弱く持ち上がる項（`_Sheen`）
   の 3 つで出す。ハイライトを 1 点でも作ると「長年使い込まれた物」ではなくなる

## 依頼を数値で確かめる

「くっきり光る所は少なめ、暗い所が多く、わずかに赤く」は絵だけでは判定できない
（赤くした時点で満足してしまう）。`far` の面を測る:

```bash
py -3.11 -W ignore -c "
from PIL import Image
im=Image.open('Assets/Screenshots/sealedbox/sealedbox_far.png').convert('RGB')
w,h=im.size; px=list(im.crop((int(w*.12),int(h*.05),int(w*.88),int(h*.95))).getdata()); n=len(px)
r=[max(0,p[0]-p[2]) for p in px]
print('はっきり赤い',sum(1 for v in r if v>25)/n*100,'わずか',sum(1 for v in r if 6<v<=25)/n*100,'無彩',sum(1 for v in r if v<=6)/n*100)"
```

2026-08-12 の実測: **2.5% / 18.9% / 78.6%**・面の明るさ平均 11/255。
時間の不安定さは連番 120 枚の面全体の赤みで **1.37 倍**振れる。

⚠ **静止画では光の走りも不安定さも判定できない。** Edit Mode は `_Time` が進まないので、
`_PhaseSec` を外から与えた連番（`logs/sealedbox/wave_*.png`）を見る。
