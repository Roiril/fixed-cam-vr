**罠**
- ⚠⚠ 霞の箱（Air）の面が部屋の中にあると、材質の AO が面に当たって壁が斑に暗くなる（丸い明るい塊が出た）。箱は壁の外まで広げる
- 汚れの強さを AO に頼る材質は、面の無い箱にも当たる。`Air` のように見えない物の位置を先に疑う
- 新しいノードを足した最初の 1 枚は OptiX のコンパイルで 2 分以上かかる。2 枚目は 13 秒。分割の重さと読み違えない
- 細かい布目の写真だけだと、離れた画でカーテンが滑らかな帯になり金属に見える。皺の写真を大きく貼って小さな折れを足す
- 細い管へ箱投影で写真を貼ると砂時計の模様が出る。三脚とパイプには濃淡を弱く掛ける
- 黒い服は鏡面と光沢を下げると平らになり、法線を強くすると影が千切れた染みになる。中間で止めたが解けていない
- FBX に付いてくる 2 コマのアクションを消さないと、描くたびに自前の姿勢が T ポーズで上書きされる（`animation_data_clear`）
- `Walking.fbx` の rest は T ポーズではなく歩きの 1 コマ。回転の差は移せない。骨の向きのベクトルを移す（swing）
- Remy の Body は服の下が無い。Body をふくらませると筋肉が服に写り、Tops と重ねると段差が出る → 骨に沿った輪と胴の幅から「包み」を作る（`_garment`）
- 基準の姿勢が T だと、腕を下ろしたとき肩が風船になる → 歩きの平均へ rest を移してから服を作る（`_rest_to_mean_pose`）
- 服の骨の重みは近い頂点から写すので、基準姿勢で近い別の部位から重みを拾う。ポケットが手の骨に引かれて黒い板になった（`allow`）。袖と胴も分ける
- 輪の向きを節ごとに決め直すと裏返ってチューブがねじれ、膜が張る。前の輪から運ぶ
- 手続きの布の折れは粘土や岩に見えた。皺の写真の明暗を形に刻むと布に見える。振幅は標準偏差 2mm 前後。大きいと影が染みになる
- 布シミュレーションを掛けたカーテンは襞の山が細く潰れ、上から下まで白い線になる。掛けない
- 手すりの影は襞の上でジグザグの棘になり布の模様に見えるので、手すりだけ影を落とさない（ここは物理と違う）
- 電球を L の角に寄せると布を真横からかすめ、山だけ光る。部屋の中央寄りへ移した（Unity 側の `Bulb` とは別の値）
- OpenCV の EXR は環境変数を立てても読めなかった → Blender で読んで `.npy` に書く
- 連番の露出はコマごとに測らない（人の出入りで明滅）。背景で 1 度決める
- 切り抜き合成の中間ファイルは 1 コマ 4MB。カメラごとに仕上げて消す（`make_movie.py`）。C: の空きが 10GB 前後しかない

**配置（2026-11-04 夜に作り直し）**: ユーザー指摘「スマホの配置や広角具合、A-B-Cの領域の置き方とか、現実とあっていない気がします」。原因は 3 つ。
- 位置を企画書の図 4 から測っていた。図 1・図 4 は**生成画像に説明線を足したもの**（`figures/SOURCES.json` に書いてある）で寸法が無い。A は実物より 0.3m 遠く、B は壁から 0.65m 離れていた
- 画角を `show.json` の 77.4 度から取っていた。無人写真に実物の枠を当てると水平 96 度（1 台ごとでは 92〜98 度）。端末の物理値 104.3 度より狭い。隠れた切り抜きか歪みの補正かは未確定
- 歩く道は全身の余白のために `padding=0.5` で外へ出ていた（`x=-0.96`）。区画の外では切替が保持され、C へ替わるのが `x=0.55` まで遅れた。手すり沿いの `path=rail` へ替えて、B は `z=-0.45`、C は `x=-0.26` で替わる

**正は** `plate_fit.py`（写真の点と線に枠を当てる）と `check_rig.py`（写真との差 A 2.0 / B 4.6 / C 2.1px）。旧 `routes` を流すと check_rig は落ちる（区画外 346 コマ・担当の一致 40%）ので計器は生きている。論文の図 `cam-*.jpg` の人でも確かめた（B の靴の幅 60px は高さ 3cm・距離 0.45m と合う。高さの根拠はこれと床の境）。
- B の高さと横位置は枠だけでは定まらない。`priors` で「床の上」「壁の脇」を与える
- C に人が映るのは担当区間の 6 割。区間の後半でカメラの真下を通るので、姿勢の誤りではない
- 部屋: 西の壁 `x=-1.03`。A は -1.2、C は -1.13 と出るので B の床の境を優先した。5〜15cm の幅がある。白い柱（南面 `z=1.03`）と棚の黒い布は写真に写るので足した。天井と電球は作品の見た目のままで、実物に合わせていない
- `calib` は別物。9/7 の会場プレートと 9/24 の無人写真は別の部屋で、B と C の calib はどちらにも枠が重ならない。合成の姿勢は未検証

**罠**: B のレンズは壁から 2.5cm なので `clip_start=0.02` だと壁が切れて画の左が黒くなる（0.003 にした）。`seq` は `Logs/twin-cycles/seq` の古いコマを黙って再利用する。
