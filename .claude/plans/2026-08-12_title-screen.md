# タイトル画面「廻リ視」— 暗い地の題字から、封印の箱の立つ現実へ

2026-08-12。ユーザー依頼:

> 廻り視(Mawarimi)のVRでのタイトル画面を作ってほしい。タイトル画面では、黒背景に目の前に
> 立体文字でタイトルがいい感じの雰囲気で置かれている感じ。周回リセットしたときに最初に
> 表示しておく感じで。コントローラーAボタンに、タイトルを閉じて体験を始めるという機能を
> 割り当ててほしい。今ついている機能はなくしてOK。（…）タイトル画面から、かっこいい感じに
> パススルーになって体験が始まるように、いい感じのアニメーションで、クロスフェードは前提で
> 文字もいい感じに動くといい。タイトル表示からAを押すと、体験者には体験エリアはすでに
> 以前作った黒いので覆われてる感じで。一瞬でも壁が見えてはいけない。

## 立ち位置 — 骨格を 1 つも増やしていない

タイトルは**導入の段 0（開始待ち）に被さる薄い層**として作った。

- `ShowPhase` を増やしていない（ゲート・終了判定・heartbeat・卓・シミュレータの分岐が一切変わらない）
- `IntroStage` も増やしていない。段 0 はもともと「体験者がエリアへ近づいてくるのを待つ」区間で、
  実測で十数秒ある。そこに黒と文字を被せるだけ
- `IntroLogic` / `IntroDirector` / `IntroVeil` を 1 行も触っていない

段の数を増やさない代わりに、**タイトルが立っている間は導入の開始合図を止める**必要がある。
門は `ShowControlClient.UserPresentProvider` 1 つ（`IntroDirector.IsAtStartSpot` の最初の門で、
false のとき `RearmStartSignal` を呼んで合図を武装し直す）。配線点は `OvrControllerBridge` —
そこが既に `OVRPlugin.userPresent` を差している唯一の場所。

## 壁を一瞬も見せない担保

依頼で唯一の絶対条件。**構造で満たしていて、待ちで補強している**。

1. 段 0 では `IntroDirector.Update` が毎フレーム `sealedBox.Apply` / `shell.Apply` を呼ぶ。
   つまり**タイトルが立っている間ずっと封印の箱は描かれている**（黒の裏で）
2. タイトルの黒は封印の箱（queue 4920）より**後**（4950）に描き、`alpha` を 1 へ戻すだけ。
   `alpha` を 0 へ戻せば、その下で既に描かれている箱がそのまま現れる
   → **開ける途中に壁が覗くフレームが構造的に存在しない**
3. 念のため、A を押してから `SealedBox.AppliedOpacity`（または `ContainmentShell.AppliedStrength`）が
   0.9 を超えるのを確かめてから黒を開き始める

⚠ **3 はラッチにしていない**。`TitleLogic.ConcealWaitMaxSec`（0.5 秒）で必ず諦めて開く。
隠すものが壊れている現場（シェーダ剥がれ等）でタイトルが永久に閉じない方が悪い
——「凍結が解けない」はこの codebase が 4 回踏んだ型。

## A ボタン — タイトルを閉じる 1 つだけ

初版は「タイトルが立っている間だけ意味を変え、それ以外はカメラ手動送りのまま」にしたが、
同日ユーザーが **「カメラの手送り機能は要らないです。なので、Aボタンでスタッフがタイトルを消して
体験を始めれるようにしてください」** と言ったので、手動送りごと撤去した。

| いつ | A の意味 |
|---|---|
| Normal モード | タイトルを閉じて体験を始める（タイトルが無ければ何も起きない） |
| Registration モード | 従来どおり点サンプル（タイトルは閉じない） |

- 入力面は**右手 4 入力のまま**（2026-07-23 の凍結を破っていない）。減らしただけ
- 撤去に伴って `OvrControllerBridge` の `registry` / `switchDirector` が不要になったので消し、
  `nextButton` は意味を失ったので **`primaryButton`** へ改名した。prefab YAML と
  `StreamingLogicPrefabFieldsTests` を同じコミットで合わせてある
- 設営でカメラを見たいときは Web 卓の 📺 カメラ固定か、Editor のキーボード
  （`CameraSwitchInput` の Tab / 1-9）。**実機のコントローラからは送れない**
- `ControllerGuidePanel.ShowTransient`（「演出中は切り替えできません」の赤 1 行）は
  唯一の呼び出し元が消えて**未参照になった**。API 自体は残してある

## 見た目 — 組んだ題字を「版」として焼く

初版は明朝を Z 方向へ 16 枚重ねた押し出しだったが、ユーザーが《夜灯す》のロゴタイプを見せて
**「このスクショみたいな感じにしてほしく、デザイン性をより高めてほしい」**と言ったので作り替えた
（`canon/LEDGER.md` 0009）。

参照から取った体裁の言語:

- 暖かい暗褐色の地（純黒だと墨が紙に載って見えず、発光する看板になる）
- 明朝の高コントラスト（游明朝 Regular。横画が髪の毛のように細いのが要）
- 白い画は**裂けたようにかすれる**。縁は硬く切る
- **1 字だけ朱**。「視」＝見ることそのものに置いた
- 字ごとに大きさも高さも変える（揃えると「フォントで打った」に見える）
- 「廻」の之繞から続く**長い払い**が右下へ抜け、少し離れて小さな一点
- 縦組みのルビ「まわりみ」と、上下の細い罫（これがあると「読み」ではなく「銘」に見える）

焼くのは `tools/make-title-art.py`。**生成モデルは使っていない** — 使ってよいと言われたが、
漢字の字形が崩れる。字はフォントの輪郭から起こし、質感だけを手続きで乗せている。

厚みは**押し出さない**。明朝の横画は重ねると潰れて太いゴシックになる。代わりに
**版を 3 つの奥行きへ置く**（添え z=+0.10 / 主 z=0 / 朱 z=-0.06）。VR の立体感は両眼視差が
主役なので、平らな版のまま層を離す方が字を殺さずに奥行きが出る。10cm 離せば 2m 先でも
視差 0.1° ＝ 立体視の閾値（0.01° 前後）の 10 倍あり、はっきり分かれて見える。

加えて 2 つ:

- 題字だけが頭に**わずかに遅れて**付いてくる（剛体として遅れる・上限 8°）
- 頭が完全に静止していても層が分かるよう、ごく遅い揺らぎ（0.3°/s 未満）を足す

⚠ **黒の面は遅らせない。** 遅らせると振り向いた瞬間に覆いの縁が視界へ入り、現実が細く覗く。

## 閉じる演出（約 2.85 秒）

**⚠ 2026-08-13 に作り替えた**（`canon/LEDGER.md` 0022「奥へ飛んでいくと箱に吸収されたみたいで変」
「廻りという名前なので、文字が中心に向かってゆがんで回転しながら焼けただれたみたいに灰になって消滅」
／ 0023「もっと、引き延ばされながら渦を書くように回転して消えていってほしい」）。

1. **0.00–0.42s** 光が字を走り抜け、字がわずかに手前へ迫る（押した手応えを**その場で**返す）
2. **0.00–1.60s** 版の中で**中心へ寄りながらねじれる**（中心 300° / 外周 30°・最終で半分になる）。
   **通ってきた道筋が尾として残る**（引き延ばし）。奥行きは動かさない
3. **0.20–1.60s** **外周から焼ける**。際に熾が光り、その内側に焦げが残り、灰が上へ流れて消える
4. **1.60–2.85s** **字が消え切ってから**（＋隠すものの確認が済み次第）黒が開き、
   封印の箱の立つ現実が出る（LEDGER 0024。それまでは 3 と重なっていて、
   **題字は現実の上で燃えていた**）

字は黒より先に消え切る。最後に残るのが黒だと、開いた瞬間に現実だけが立ち上がって**継ぎ目が 1 回**で済む。

**捨てたのは 2 つだけ**: 奥へ 0.55m 退くこと（`RecedeM`）と、「光に還る」削れ際。
出現・保持・黒の開き方・A の意味・音の縁は 1 ビットも変えていない。
値と罠は [memory/title_screen.md](../memory/title_screen.md) §4.5。

## 出す / 引っ込める条件

| 事象 | 動き |
|---|---|
| 起動（相が Intro） / ▶ ラン開始 / 右グリップ 2 秒長押し | 頭から出す |
| 右 A | 閉じる演出へ |
| 卓の ⏭ 等で導入が段 0 を出た | **演出なしで即畳む**（コントローラが死んでいる現場での唯一の出口） |
| 位置合わせ中（`CourseRegistrationActive`） | 譲る。時計も止める（再開したら続きから） |
| 相が Run / Finished | 出さない |

⚠ 位置合わせ中に譲るのは 2026-08-07 の実害と同型の理由。タイトルの黒は 0.3m・queue 4950 で、
登録ガイダンス（StatusHud・1.6m）より**手前かつ後に描かれる**ので、譲らないと作業中のスタッフに
文字が 1 つも見えない。

## 検証

- EditMode 1121/1121（`TitleLogicTests` 11 本 + `TitleShaderInclusionTests` 3 本を含む）
- 版そのものは `py -3.11 tools/make-title-art.py --preview` が出す PNG で見る。

- ⚠ **プレビューは 2026-08-13 まで真っ黒な絵を出していた**（段 `Wait` の追加に追随しておらず、
  題字が一度も呼び出されていなかった）。いまは `hold` の明るさを数えて落とす。
  **ここより前の「Editor プレビューで確認した」は、閉じる演出について何も言っていない**
- Editor プレビュー（Play 不要）で出現 / 保持 / 光の走り / A の閃光 / 焼け / 開き切り を確認。
  **背景には本物の封印の箱を置いてある** — 単色の背景で撮ると「黒が開いたとき何が見えるか」を
  判定できないため
- **⚠ 実機未検証。** 立体感・大きさ・怖さは被らないと分からない（`rules/visual-verification.md`）
