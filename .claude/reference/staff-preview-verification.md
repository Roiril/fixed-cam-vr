# スタッフ画面の描画検証

`StaffSetupPreview` は実パネルを18画面描く。CSVで文字ごとの描画とパネル境界と列境界を測る。空白画像を通すと全字が欠落になる対照も行う。画像の数だけで合格にしない。全画像を一覧にし、位置合わせと異常と引き渡しの原寸画像も読む。

TMPの文字領域は左端に負の余白を持つことがある。右寄せの末尾にも同じことがある。パネル内に見える場合でも列境界の検査を緩めない。共通の左寄せラベルは左右に列幅の1%の内余白を持つ。本体ラベルは右に2%の内余白を持つ。修正後に全18画面を描き直し、欠落とはみ出しが0であることを確かめる。

別の停止箇所を順に直しても同じ検証を繰り返し停止した場合はadvisorへ判断を渡す。失敗を除外したり、画像を省いたりして完了にしない。

2026-10-10: 右寄せ本体ラベルの末尾と位置合わせVerifyの先頭で検査が停止した。内余白で修正する方針をadvisorと確認した。

タブレットの文面を変更するときは同じ文面を検証する`verify-runtime.cjs`の期待文字列も同じ変更で更新する。実ブラウザの検証ではmockのpulseが異常カメラや本編や終幕の状態を上書きしないことを先に確かめる。正常画面と異常画面の両方を流してから測る。
