# ドキュメント同期（必須）

**コードや機能を変えたら、その変更を反映したドキュメント更新を同じ作業・同じコミットで行う。**

## ⚠ 置き換える。積まない（2026-10-22）

`rules/streaming.md` は 351KB、`rules/show-design.md` は 188KB まで膨らんだ。
日付つきの節を頭に足し、古い記述を「これは前の版」と断って下に残す書き方を続けた結果で、
該当コードを触るたびに 18 万字が載り、本文の途中を拾ったセッションは前の版を契約として読んでいた。

- **rule には現行の契約だけを書く。** 変わったら、その行を書き換える。日付の節を足さない
- **旧い記述は消す。** 経緯は git log と `reference/archive/`（凍結。追記しない）にある。
  前の版だと断る見出し語を rule に残さない（語の一覧は `tools/harness-check.py` の `OLD_WORDS`。見つけたら落とす）
- 経緯・実害の物語・測った数値は `memory/` に書く。rule からは 1 行で指す
- rule が上限を超えたら、要約して縮めない。節ごと `memory/` か `reference/` へ移し、rule には指す行を残す
- **体験者に見えることが変わったら `canon/NOW.md` の該当行も直す**（`py -3.11 tools/canon-now.py` が引用と区間の過不足を検査する）

## 更新先

| 変えたもの | 反映先 |
|---|---|
| 構成・ビルド / 起動方法・ディレクトリ | [README.md](../../README.md) |
| コードの契約（破ると壊れること） | 該当する話題の `.claude/rules/*.md`（`paths:` で自動的に載る） |
| 体験者に見えること | `canon/NOW.md` |
| 罠・経緯・実測 | `.claude/memory/*`（`MEMORY.md` に 1 行） |
| ハーネス全体の導線 | [CLAUDE.md](../../CLAUDE.md) |

## やり方

1. コード変更とドキュメント更新を 1 コミットにまとめる
2. 数行でよい。「何が決まっているか」と「踏みそうな罠」を書く
3. `.claude/` を触ったら `py -3.11 tools/harness-check.py` を通す（Edit / Write の後に hook も警告する）
