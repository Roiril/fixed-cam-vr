# 合成マスクを作る

素材の全範囲を残し、実写とつながる場所に境界を置く。
このプロジェクトでは人物だけを切り抜く方式へ置き換えない。
ユーザーの2026-09-19の指示と既存の採用素材を保つ。

## 作業前

- `.claude/memory/material_flow.md` を読む。素材座標と16:9の枠座標を混同しない。
- `.claude/memory/composite_mask_quality.md` を読む。現在の採用と再生成コマンドはここにある。
- 原画像、無人画像、現マスクを別々に開く。動画は全コマを走査し、先頭・中間・末尾と範囲が最も広がるコマを開く。
- 加工済み素材だけで判断しない。直線が素材自体へ焼き込まれていたら、元動画へ戻る。マスクを広げても消されたシミは復元しない。
- マスクを掛けるのは1回だけ。素材へ無人画像との合成を焼き込み、表示時に同じマスクを掛けると濃さが二重に減る。`prepare_video.py` は黒帯除去とサイズ合わせだけを行い、未合成の動画と実際の最終コマを出す。

## 残す範囲を決める

シミは濃い目や口だけでなく、薄いにじみと飛び散りまで含める。
矩形は探索範囲に使えるが、完成マスクの輪郭には使わない。
探索範囲へ対象が接していたら範囲を広げる。実物のパイプなどが隠す境界と区別する。

`scripts/build_mask.py` は以下の3方式を持つ。

- `difference`：全コマと無人画像の差を使う。弱い差の領域を、濃い差や指定した範囲から拾う。離れた染みも残す。濃い領域の内側をぼかさず、余白を確保した外側で透明へ移す。
- `region`：背景も描き直されて差分を信用できない素材に使う。全コマを見て、染みが広がる範囲を不規則な多角形で囲う。薄い枝や尾も囲いに含める。その内側を保持し、外側の余白で透明へ移す。多角形の座標を保存するので再生成できる。
- `surface`：壁の面全体を多角形で指定する。壁が無い場所にも出す演出なので、元画像と色が似ている場所を穴にしない。画像外まで続く辺をフェードさせない。

差分は対象の正解ではない。布の描き直しや照明差も拾う。
画像の位置と明るさを先に確認する。候補を画像へ重ねて、実際のシミと一致するか見る。
必要な範囲は `core_polygons` で補える。消してはいけない尾を閾値だけで落とさない。
生成素材に含まれるパイプや支柱は、そのまま一緒に合成する。実写を残す穴を勝手に開けない。
2026-09-19 にパイプの保護帯でシミを再び直線に切り、ユーザーから保護自体が不要との指摘を受けた。
`protect` は実写の特定部分を残す明示的な要件がある場合だけ使う。その場合も大きな帯で代用せず実物の輪郭を拡大して確認する。

## 再生成

```powershell
py -3.11 .claude/skills/composite-mask/scripts/build_mask.py --recipe <recipe.json> --out-dir <出力先>
```

レシピの形式は [references/recipe.md](references/recipe.md)。入力の相対パスはレシピの場所を基準にする。
画像の寸法が違うときは黙って伸ばさず、元動画の黒帯などの変換を明示する。
マスクの書き出し時だけ素材座標から640×360へ収める。素材がない黒帯へ白をはみ出させない。
出力の `report.json` は入力ハッシュと設定を含む。素材が変わったら作り直す。

## 見て確かめる

1. 元素材／旧マスク／新マスク／新しい合成を並べる。ラベルは実在するファイルから付ける。
2. 対象を残す中心部分がほぼ不透明か確かめる。細い染みも分母へ含める。
3. 完成マスクで薄い尾や動いた口が切れていないか全コマで調べる。`core_coverage` は指定した範囲の保持率であり、シミ全部を発見した証拠ではない。静止画像1枚で動画を合格にしない。
4. 外周を拡大する。水平・垂直な切断、二重の折り目、明るさの帯が出たら戻す。色の差が小さい場所まで余白を調整する。ぼかしを増やすだけで済ませない。
   内部に穴を開けていれば、その要否と輪郭も同じ検査の対象。最初の旧版だけでなく、直前に提示した候補と修正版を同じコマ・同じ倍率で比較する。全景の縮小画像だけを合格根拠にしない。
5. `tools/gen-plate/screen.py` の後処理を通した画も見る。机上プレビューは実機の合格証明にはしない。
6. 既存マスクを上書きせず版名を変える。旧URLと新URLを記録する。卓が動いていれば `/state` を取り直して対象cueだけ更新し、反映番号と配信ファイルのハッシュを確認する。

比較の書き出しには `scripts/preview_masks.py` を使う。`--reference`、`--old-source`、`--new-source`、`--old-mask`、`--new-mask`、`--out-dir` と `--lap` を指定する。前後の素材は同じコマ数にする。全コマの並置と動画、後処理を通した先頭・中間・末尾を出す。短い640×480の演出素材用。

人物が素材の中を通過する問題は、固定マスクでは解決できない。
この作業の結果を「人物の重なりも解決した」と報告しない。素材の配置と動線の問題として別に記録する。

## 道具の検査

```powershell
py -3.11 -m unittest discover -s .claude/skills/composite-mask/scripts -p test_build_mask.py
```

範囲を故意に狭くした入力が止まることも確かめる。検査が通る入力だけで校正しない。
同じ入力とレシピを2回処理し、マスクのハッシュが一致することを確認する。
第三者へ画像を送る処理や、人物抽出モデルの導入をこのスキルから追加しない。
