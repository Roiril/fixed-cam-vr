# 当日の手順 — 目の写真（3 周目 C の視界ジャック）

**やることは 3 つだけ。** 開場前に 5 分あれば終わる。

## 1. 撮る

会場に人形を置いた後、**人形が立っている場所から、人形の目の高さで**何枚か撮る。
3 周目 C で目が開いたとき、その目が見ている画になる。

- **枚数は 4〜8 枚**（総尺 2.4 秒を割るので、3 枚なら 1 枚 0.5 秒 / 8 枚なら 0.3 秒）。
  12 枚を超えた分は使われない
- **いろんな視点から**。同じ構図が続くと「写真が切り替わった」ではなく「1 枚が明滅した」に見える
- 明るさ・向きは気にしなくてよい（PC が揃える）

## 2. 送る（PC は触らない）

撮った端末のブラウザで **`http://192.168.10.10:8099/onsite.html`** を開き、
**目の写真 → 写真を選ぶ → 送って反映する**。1 押しで下の 3 つが終わる。

- 卓へ置く（**押した順に番号を打ち直す** — 流れる順はファイル名順なので）
- 取り込む（長辺 1280 へ縮小・EXIF の向きを画素へ焼く・減光 0.72・JPEG q85）
- **APK の焼き込みも更新する**（卓が居ない状態で Quest を起動しても同じ体験になる）

**やめる / 差し替える**: 同じ面の「全部消す」。消すとジャックは出なくなる（**目は従来どおり出る**）。
差し替えは「全部消す」→ 選び直して「送って反映する」。

### シュビーに頼む場合

```bash
py -3.11 tools/onsite.py eyejack
```

写真の置き場所を**当てにせずに探す** — 卓の取り込みフォルダ、`G:\マイドライブ\shubie\eyejack-drop`
（スマホの Drive から放り込める）の順。見つけた順に番号を打ち直してから同じ経路を通す。

### 手で置く場合（従来）

`tools/web-compositor/eyejack/` へ入れて、卓の **👁 目の写真 → 📥 取り込む**。
卓のパネルの「📂 フォルダを開く」でそこが開く。

⚠ **流れる順はファイル名順。** 順序を決めたいなら頭に番号を付ける（`01_...` `02_...`）。

## 確かめる（2 つとも見る）

| 何 | どこ |
|---|---|
| **卓に何枚あるか** | 👁 目の写真パネルの一覧（枚数・寸法が並ぶ） |
| **Quest に何枚届いたか** | ライブ状態の **「目の写真 — Quest に N 枚 届いています」** |

⚠⚠ **2 台使うなら、2 台とも上の行を見る。** 片方だけ届いていないのは**画にも音にも出ない** —
その機に当たった体験者だけ写真が出ない（目は出るので、見ていて気づけない）。
届いていなければ卓との接続を確認する（**30 秒ごとに自動で取り直す**ので、繋がれば黙って揃う）。

## 写真を差し替える / やめる

- **差し替え**: フォルダの中身を入れ替えて **📥 取り込む** をもう一度押す
- **やめる**: フォルダを空にして **📥 取り込む**。ジャックは出なくなる（**目は従来どおり出る**）

## 卓が無い機で走らせるなら

写真を取り込んだ後に **📦 ビルド用エクスポート → APK を焼き直す**。
焼き込んだ写真は卓が居なくても出る。

## 出るのはどのカットか

タイムラインのカット詳細で **「視界ジャック（当日写真）」** に印が付いているカット
（いまは 3 周目 C の 2 カット）。印は「闇の目」が 0 より大きいカットにしか出ない。

## 体験者から見た流れ

1. スクリーンの外の闇に目が開く（いつもどおり）
2. 目が開き切る、または**区間の半分まで歩いた**ところで**視界が写真に乗っ取られる**
3. 写真が 2.4 秒ぶん切り替わる
4. 視界が戻り、**目が閉じて終わる**

⚠ 歩き続けた体験者が次の区間へ入ったら、写真は**その場で止まって**視界が戻る（仕様）。
