1. 立ち上げる

15:40 時点で B（192.168.11.20）と C（192.168.11.23）は配信中です。 A だけ beacon を出していないので、その 1 台を起動してください（電源かアプリが落ちています）。

  • カメラ A の端末で fixed-cam-streamer を起動する。画面に A が大きく出ます
  • Quest の Wi-Fi を 5GHz に繋ぎ直す。 2.4GHz だと受信が配信の 2/3 まで落ち、 導入の最後の段（映像へのすり替え）は映像が届いていることを要求するので、帯域が細いだけで演出が出ません
  • ブラウザで http://localhost:8099/ を開き、コンソールタブでカメラ 3 台が映っているのを見る

IP は DHCP なので変わることがありますが、 卓が beacon で自動追従します。映らないときは卓の「🩺 疎通診断」を押すと、 PC→カメラ・beacon・Quest の 3 経路が ✅ / ❌ で出ます。beacon ✅ で HTTP ❌ なら AP のクライアント間通信が切られています（技術では直せないので自前 AP へ）。

スマホが Doze で寝ていたとき

画面が消えた状態でアプリを起動すると、HTTP サーバだけ生きてフレームが 0 のままになります。 画面を点けてロックを解除してから起動してください。

2. 位置を合わせる — HMD で 2 点（約 10 秒）

  1. Quest で 廻リ視 を起動する
  2. 右トリガーを 2 秒長押し。登録が残っているので確認画面に着地します
  3. A を押して点 1 から取り直す
  4. 壁の両端（図 1 の ▲）の真上、床から 1m の高さ（手すりの高さ）にコントローラの先端を構えて、A を 0.5 秒ホールド。 進捗バーが出ます。2 点を順に
  5. 最大残差が出ます。0.12m 以下なら合格。B で確定

合わなければ A でやり直し。抜けるときは右トリガー 2 秒長押し（保存しません）。

2 点を同じ高さで構えるのが精度の条件です。 構える高さは卓の「構える高さ」（layout.regTouchHeightM）で 1.0m にしてあり、 HMD の指示にも「床から 100 cm の高さで」と出ます。同じ高さから床の高さも測ります（タッチの高さ − 1.0m）。 点ごとの高さのばらつきが 6cm を超えると警告が出ます。手すりの上に先端を置くと高さが揃います。

ワイヤーが実物に重なるか見る

確定すると、壁と床の外周が線で表示されます。実物のパーテーションと床の縁に重なっていれば合っています。 ずれていたら A でやり直してください。

3. 通してみる

  • 開始位置に立ち、床の線を横切ると導入が始まります（13 秒）。 現実の見えから色が抜け、輪郭が浮き、枠が閉じて、中がカメラ映像に変わります
  • そのあと A→B→C を 3 周。3 周したあと戻ってきた A で終わります。全体で 3 分ほど
  • 卓のラン状態パネルに相・周回・経過・いま画面を握っているものが出ます

次の人に替えるときは卓の ▶ ラン開始。卓を見ていないときはスタッフが 右 A を 2 秒長押ししても同じことが起きます。右グリップは使いません。

4. カメラを合わせる — 卓で手で（1 台 5 分）

人形を映像になじませるための作業です。3 台とも一度も合わせていません。 段 3 で人形の立ち位置がずれて見えたらここへ。

  1. 卓のカメラ列の 🎯 カメラを合わせる を押す
  2. ライブが 1 枚静止し、その上に部屋の線と人形が重なります
  3. ドラッグで床と壁を動かす／ホイールで前後／Shift+ドラッグで平行移動
  4. X / Y / Z キーでその軸だけに拘束（もう一度押すか Esc で解除）。自由回転は床を回す Y 軸だけです
  5. 床の線と壁の縦線が実物に重なったら 💾 このカメラに保存

掴んでいるのは床と壁ですが、保存されるのはカメラです。 layout.room は 3 台のカメラが共有する実測値なので書き換わりません。

触ってはいけないもの：🔍 レンズ（画角・歪み）。 「画角を広げて近づける」と「狭めて遠ざける」は画の上でほぼ同じで、ここを合わせ込むと位置が実測で 27cm ずれます（固定すれば 2cm）。

📐 部屋（床の寸法）も、巻尺で測った値以外を入れないでください。3 台で共有しているので、 1 台に合わせてずらすと他の 2 台の合成が黙って狂います。

📱 端末の傾きは、いまは取り込めません。 実機の streamer が v0.7.0 で傾きを送っていないので、 パネルは「この端末は傾きを送っていません」と出ます。位置と向きを手で合わせてください（末尾に更新手順）。

合成の見た目を判定する場所

卓の人形は幾何の目安で、陰影・素材・法線は描いていません。 見た目の良し悪しは Unity の Tools/FixedCamVr/Diagnostics/Preview Show Composite で見てください。

数字で確かめたいとき

HMD をかぶらずに導入から 3 周までを通せます。

bash tools/run-quest-xp-test.sh walk 300

出るはずで出なかった演出を名指しします。画も要るときは：

python tools/quest-record.py --sec 45 --walk

補足 — 配信スマホを v0.9.0 にする

端末の傾き（上下・傾き）を /info で配るようになり、卓の「📱 端末の傾き → ⤵ 取り込む」で 手で合わせる自由度が 6 から 4 に減ります。USB 接続が要ります（無線 adb は 3 台とも塞がっています）。

cd ../fixed-cam-streamer && ./gradlew installDebug

入れたら端末を水平に置いて上下が 0° 付近になるかを見てください。 センサの符号は実機でしか確かめられません。左右の向き（方位）は送っていないので、そこは手で合わせたままです。
