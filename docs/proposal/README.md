## 概要

1990 年代のサバイバル 3D ホラーでは、シーン内に固定して設置されたカメラを通して、自身が操作する
キャラクターを見る視点構成が用いられていた。本企画では、この固定視点を HMD と複数台のカメラを用いて
現実空間上に再構成する。固定視点では画角が変化しないため、視界の一部または全体を事前録画映像や
生成映像へ自然に差し替えられる。差し替えの対象は、周囲の場面だけでなく画面の中の自分にまで及ぶ。
これらの映像操作に、固定画角ゆえに生じる死角の演出を加え、日本人形との追跡劇を軸としたホラー体験を構成する。

キーワード：固定視点／Substitutional Reality／サバイバルホラー／HMD／AI 映像生成

## 2. システム構成

### 2.1 物理構成

実空間中央に L 字型の壁を設置し、その周囲を体験者が移動する経路とする。固定視点を構成するため、
三脚上に設置したスマートフォン 3 台を固定カメラとして配置する。**床は 1.8m × 1.8m、L 字壁の高さは 1.8m**（図 1）。

小型の日本人形を搭載した**移動台車**を用いる。無線操作に対応しており実空間内を移動可能で、
追跡演出ではこの人形が経路上を移動し、体験者を追跡する。

### 2.2 固定視点での映像表現

各スマートフォンで撮影した映像は Wi-Fi 経由で伝送され、HMD 内の仮想スクリーン上へリアルタイムに
提示される。HMD には**いずれか 1 台の固定カメラ映像のみ**が表示され、スクリーン外の領域は黒背景とする。
体験者は現実空間をスクリーン越しにのみ観察する。提示するカメラ映像は、体験者の位置に応じて自動的に切り替わる。

### 2.3 映像差し替えと合成処理

提示映像の一部または全体を差し替える。差し替え素材は 3 種：

1. 事前に撮影した映像
2. **体験中に録画した映像**
3. 固定画角の実写フレームを入力として画像・動画生成モデルで制作した映像

固定視点では差し替え領域のマスクをカメラごとに静的に用意すればよく、境界にはフェザリングや
多重帯域ブレンディングを、差し替え素材の全体には**色統計マッチング**を施し、実写映像と継ぎ目なく合成する。
さらに、合成後の映像全体に色調補正や走査線・粒状感などの効果を施し、固定カメラ映像らしい質感に整える。

差し替えはフェード付きで再生され、提示映像の切替と同様に、体験者の位置に応じて実行される。
また、**ノイズやグリッチ等の乱れを一時的に重畳でき、差し替えの継ぎ目の隠蔽や、体験者の注意・移動の誘導に用いる。**
映像伝送の視覚遅延は、SR システムで置換が成立した実績値を参考に、**100 ms 程度以内を目標として管理する**。

## 3. 体験の流れ

経路は 3 つの区間から構成され、各区間をカメラ A、カメラ B、カメラ C が担当する。
体験者は固定カメラ映像のみを見ながらこの経路を **3 周**し、各周で異なる演出を体験する。
**体験全体は導入を含め 3 分以内**とし、**各周をおよそ 30 秒**で構成する。

**導入**：体験者は HMD を装着し、まず区間 1 を固定視点下で歩行する。固定視点による移動に慣れた後、
日本人形との追跡体験を開始する。周回中は安全確保のため、右手で壁をたどりながら移動する。

**1 周目**：映像の差し替え演出は行わず、**体験者の行動映像を録画する**。一方で、固定視点によって生じる
死角を利用した演出を行う。体験者が右手でたどってきた壁は死角に入って見えないが、視点が切り替わった瞬間に、
その壁が一面の血の手形で覆われていたことに気づく。

**2 周目**：映像差し替えによって、提示映像の中の日本人形を実写調の怪物へ置き換える。怪物の映像素材は、
当該カメラの固定画角フレームを入力とした動画生成によって制作する。怪物が画面内で体験者へ接近し、
襲いかかる演出を行う。実空間上では小型人形であるにもかかわらず、映像上では異なる存在へ変貌して見えることで、
不安感を強調する。**差し替えは体験者の歩行や提示映像の切替のタイミングに同期させ、差し替えの知覚的検出を抑える。**
あわせて**差し替えの前後に映像の乱れを挿入し、伝送の劣化を装って継ぎ目をさらに隠す**。

**3 周目**：1 周目に録画した映像を背景として用いる。その上に、**体験者が操作可能な CG 人形**を重畳し、
操作対象と画面の中の自分が入れ替わる演出を提示する。このとき、画面内を歩き続ける体験者の映像は
1 周目に録画された過去の映像であり、現在の体験者の動作とは同期していない。そのため体験者は現在の自分の
身体ではなく、人形側の存在として行動することになる。結果として、「人形となった自分」が「過去の自分の身体」を
追跡するという構造が成立し、これまで自分を追ってきた人形が実は自分自身だったのかもしれない、という反転が生まれる。
