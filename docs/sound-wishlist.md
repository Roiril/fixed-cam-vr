# 音の依頼リスト（フリー素材）

**合成では作れないものだけを頼む。** 2026-08-12 時点で 17 本は自前合成で焼いてあり
（`tools/make-sounds.py`）、トーン・唸り・ノイズ・電気の音・リレー・掃引・共鳴体は
合成の方が制御できる（ループの継ぎ目が数学的にゼロになる、音量を LUFS で厳密に揃えられる）。

**合成が苦手なのは、細かい不規則さが本質になっている音**。以下はそれに当たる 5 つ。

⚠ 落としてきてもらったら `Assets/Resources/Sound/` へ置き、
`py -3.11 tools/sound-lint.py` を通してから `.\tools\unity.ps1 menu sound-import`。
**48kHz でないもの・ステレオで逆相のものは lint が落とす。**

---

## 欲しいもの（優先順）

### 1. りん（仏具の鈴）の単発・減衰が長いもの

いまはタイトルで**合成のりん**が鳴っている（非調和の部分音＋唸り）。実物は撞木が当たる瞬間の
細かい雑音と、鉢の歪みから来る不規則な唸りを持っていて、そこが「本物らしさ」の正体。
**この作品でいちばん最初に鳴る音**なので、ここだけは実録が効く。

- 単発・無響（残響が焼き込まれていないもの）・**5 秒以上減衰するもの**
- 「鈴」より「りん」「おりん」で探す方が当たる

### 2. 家鳴り・木の軋み（短い単発を 3〜4 種）

**和ホラーの中核で、合成では作れない。** 段 0（封印の箱の外に立っている）と本編の間に
まばらに置くと、「古い建物の中に閉じ込められている」が音だけで立つ。

- 1〜3 秒・単発・**低い方に体があるもの**（きしみだけの高い音は効かない）
- 「家鳴り」「木 軋み」「床 きしむ」

### 3. 息を吸う音（人・静かなもの）

タイトルを閉じる瞬間（A を押す）に使う。いまは合成のノイズ掃引で代用しているが、
**人の息であることが分かる**必要がある — 体験者は「自分が息を呑んだ」と読む。

- 0.5〜1.5 秒・**息だけ**（声が混ざっていないもの）・近接録音

### 4. 重い金属の扉／シャッターが閉まる音

段 1「隔離が閉じる」に重ねる。合成した掃引＋衝撃＋中域の当たりは形としては正しいが、
**実体としての重さ**（金属が撓む音、ラッチが落ちる音）が足りない。

- 1〜3 秒・**残響が短いもの**（広い場所で録ったものは「屋外」に聞こえる）
- 「シャッター 閉まる」「鉄扉」「金庫 閉じる」

### 5. 衣擦れ（布・着物）

**まだ使い道が決まっていない**（`canon/OPEN.md` の案）。CG 人形は市松人形で赤い着物を着ているが、
いま音を持っていない。画面の中の物に音を付けるかは世界観の判定なので、素材だけ確保しておく。

- 0.5〜2 秒・数種・**乾いた布**（絹の光沢のある音より、綿・麻の鈍い音）

## 探す先（ライセンスを確かめてから落とす）

| サイト | 条件 | 向いているもの |
|---|---|---|
| [効果音ラボ](https://soundeffect-lab.info/) | **商用無料・クレジット不要・報告不要。** 再配布と AI 学習用途は禁止（[利用規約](https://soundeffect-lab.info/agreement/)） | 2・3・4。和風とホラーの分類がある |
| [OtoLogic](https://otologic.jp/free/license.html) | **CC BY 4.0**（「OtoLogic」のクレジット表示が要る）。有料で表示不要にもできる | 1・5。生活音・和楽器が厚い |
| [freesound](https://freesound.org/) | 素材ごとに違う。**CC0 だけに絞って探す**（要アカウント） | 1・5。実録の質が高いが玉石混交 |

freesound で CC0 だけに絞る検索の形（`q=` を差し替える）:

```
https://freesound.org/search/?q=rin+singing+bowl&f=license:%22Creative+Commons+0%22
```

⚠ **クレジット表示が要る素材を使ったら、展示のクレジットに必ず載せる。**
どれをどこで使ったかは `docs/sound-credits.md` に足すこと（まだ空でよい）。

⚠ **AI 学習用途の禁止条項がある素材がある**（効果音ラボ）。この作品では学習に使わないので問題ないが、
将来「素材から生成する」ような使い方をするなら条項を読み直す。

## 頼まないもの（合成で足りている）

部屋のトーン／封印の箱の唸り／装置の搬送音・電源の唸り／砂嵐／カメラ切替のリレー／
映像の乱れ／破砕の粒／掃引。いずれも **`tools/make-sounds.py` を回せば同じ音が何度でも出る**
（乱数種が固定してある）ので、差し替えるより数値をいじる方が速い。
