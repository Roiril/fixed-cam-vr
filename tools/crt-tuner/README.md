# CRTの調整

`powershell.exe -NoProfile -ExecutionPolicy Bypass -File tools/unity.ps1 crt-tune`
で起動し、`http://127.0.0.1:8107/`を開く。終了は同じコマンドの末尾へ`stop`を付ける。
この画面はUnityの実際の素材と加工を使って描画する。起動中は同じプロジェクトのビルド・テストを待つ。

基準と初期値は0303で本人がWeb調整して採用した本編の枠なしスクリーン。
通常加工0.5・表示RGB gain0.85を最初から使う。中心+3.63EV・範囲1.68・なだらかさ3、
寒色の強さ1・寒色寄り1、赤のぼけ2.25px・緑青0.65px・色ずれ10・ゆがみ0.155を含む。
「本編の採用値に戻す」「初期値に戻す」はこの23項目の初期値へ戻す。
基準値は`CrtSignalProfile`の本編定数を直接参照する。
本編の通常時はほかの加工を位置で増やさず、暗部ノイズだけ1-A=.05〜3-A=.2へ増える。
この調整画面では位置進行を再生せず、暗部ノイズの入力値を固定して比較する。
更新後は採用版専用の保存領域で開く。旧版の保存値は残し、「更新前の調整を読み込む」で任意に復元できる。
スライダーと数値入力は同じ値を扱う。A/B/Cの無人写真、変更前、参照画像を切り替えて比較できる。

「調整する画面」で通常画面・人形視点・人形化後を切り替える。人形視点は本編2-Cの加工量1・暗部ノイズ.175を基準にする。
人形化後は加工量1・暗部ノイズ.2。最新の無人原板へ本編のCG人形を合成する。
人形は各カメラの区間内で全身が見える代表位置へ固定する。追従や時間進行は再生しない。
各画面の調整値は別々に保存し、切り替えても混ざらない。
「映す素材」では無人写真のほか、人形視点の遠景と①〜④を選べる。
人形視点の素材は`show.json`に登録された5動画の0.5秒の静止コマ。動画再生やカットの乱れは再現しない。
映像の寸法・画角を保って切り出し、Unityの本編と同じOverlay経路で加工する。
人形視点素材は本編でもLiveTex向けPSFを通らないため、赤・緑青のぼけと色の位置ずれは無効表示にする。
無人写真を選べばこの3項目も調整できる。加工量1の間は彩度も無効表示とし、加工量を下げると復帰する。
値の保存は維持し、効いていると見せかけない。
生成コマとsource/frameのSHA記録は`G:/マイドライブ/shubie/reports/2026-11-01_crt-pov-tuner/frames/`。
起動時の`prepare-pov-frames.py`が検証し、元動画が変われば作り直す。素材欠損は代用せず停止する。
範囲は強い加工も試せる設定。中心は-6〜+6EV、露出は-10〜+10EV、画面の明るさは0〜4、
コントラスト・彩度は-4〜8、色温度・緑とマゼンタは-5〜5、黒の明るさは-1〜1。
中心の範囲は0.05〜4、なだらかさは0.1〜16、色づけは0〜100%、ぼけは0〜8px、
ゆがみは-0.2〜1、色ずれは-10〜10、粒・走査線は0〜4、カメラのノイズは0〜2。
通常加工・周辺の暗さ・中性色から寒色への補間は0〜1、帯域制限はON/OFFのまま。
ぼけは本編と同じ9点カーネルなので、大きな値では変化が緩やかになる。採用値と入力の細かさは変えない。

調整値はブラウザへ保存する。「設定を保存」でJSON、「PNGを保存」で表示中の画像を残せる。
JSONには通常/人形視点/人形化後の区別と素材も保存する。読み込むときは同じ画面モードを選ぶ。旧JSONは通常画面として扱う。
設定を読み込んでも`show.json`やQuestの値へは自動保存しない。
外枠は初期表示で非表示。「黒い外枠を表示」で比較できる。枠なしのPNG保存は背景透過。
切り抜きは参照Frameの開口alphaを使い、筐体のほぼ不透明な領域の生成ノイズを除いている。
Webでは映像の画素と曲面の形を変えず、表示・保存時のalphaだけを変更する。
0302の形と0303の調整値が本編へ採用された。本編は外側をdiscardし、映像内部のalpha1を保つ。
中心と色は本編と共通のガラス前の式で一回だけ計算する。今後のUI調整値を本編へ自動反映はしない。

APIはlocalhost専用。`GET /api/config?mode=normal|doll|transformed`が調整範囲・初期値・素材一覧を返し、
`POST /api/render`が`{camera,mode,source,parameters}`に対応する実GPU PNGを返す。
`mode`省略はnormal、`source`省略はliveで既存APIと互換。基準PNGもmode/source別に読む。
実装は`CrtTuningServer`と`CrtTuningAdjustment.shader`。新しい依存は使わない。

採用画像の再現とノイズの描画検証は`tools/unity.ps1 menu crt-selected -Set out=<空の出力先>`。
採用元のJSON/PNGは`G:/マイドライブ/shubie/reports/2026-11-01_screen-profile-adoption/`。
比較元が欠けていれば代用せず停止する。実機検証とは区別する。
