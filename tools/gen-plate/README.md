# 無人プレートに何かを足した素材を作る

カメラで撮った無人の部屋（プレート）へ、生成 AI で人形などを足して cue の素材にする。
4 周目 A の「左半分に大量の人形」がこれで作られている（`canon/LEDGER.md` 0050）。

## 三行で

**生成 AI に渡すのは「少し暗くしただけの環境」。** 監視カメラらしさ（彩度・ヴィネット・
コントラスト）は実機の post の役目で、種に焼くと**モデルがそれを直そうとして画を作り替える**。
**左右で指示を分けない。** 全体に 1 つだけ約束させ、置かない側は「置かないで」とだけ言う。
**回して判定器で選ぶ。** 6 回中 4 回が合格という当たり外れなので、機械で落とす。

## 手順

```bash
# 1) 種を作る（露出だけ。--full-post を付けない）
py -3.11 tools/gen-tone.py dim <プレート.jpg> seed.png --cam A

# 2) 生成（prompt の入力パスを seed.png の絶対パスへ書き換えてから）
#    ~/.claude/skills/codex → codex-run.ps1 -Mode image -OutImage out.png

# 3) 判定（合格するまで 2 を繰り返す）
py -3.11 tools/gen-plate/judge.py seed.png out.png

# 4) 明るさを戻して素材にする（dim と同じ指定で）
py -3.11 tools/gen-tone.py undim out.png tools/web-compositor/captures/<名前>.png --cam A
```

`prompt-dolls-left.txt` が完成したプロンプト。別の素材に使うときは「人形の置き方」の節だけ
書き換える。**「絶対に変えないもの」の節は触らない** — そこが効いている本体。

## 判定の合否（`judge.py`）

| 見るもの | 線 | なぜ |
|---|---|---|
| 寸法 | 640x480 | モデルは黙って拡大する（1448x1086 で返ってきたことがある） |
| 左右の明るさが揃う | 差 ≤ 0.03 | 片側だけ塗り直されると画面の真ん中に段差が出る |
| 入力の明るさを保つ | 0.95〜1.05 | 生成の露出ずれ |
| コントラストを保つ | 0.85〜1.20 | モデルは既定で「綺麗に」しようとする |
| 左に人形が居る | 差 ≥ 12 | 何も足されていない出力を掴む |
| 右を触っていない | 差 ≤ 8 | 置かない側が塗り直されていないか |

⚠⚠ **数値が全部緑でも絵は必ず開く。** 実測で、1.000 / 1.000 / 1.000・差 0.0 と完璧な数値の
出力が、**人形が床に乗っておらず切り抜きを並べたよう**に見えた。判定器は落とすためだけに使う。

⚠⚠ **完璧すぎる数値は「生成していない」印のことがある。** 上の 1 枚は、Codex が
**緑背景で人形だけを描き、PowerShell でクロマキー合成していた**（作業ファイルが
プロジェクト直下に残っていて発覚）。背景を触らないのは当たり前で、そのぶん人形は
場に馴染まない。差 0.0 が続いたら、**出力だけでなく Codex が何をしたかも見る**
（codex-run.ps1 が出す last_message_file と、プロジェクト直下に置き土産が無いか）。

⚠ **人形以外の素材へ流用するときは、判定の窓（`DOLL` / `NODOLL` / 帯）を必ず引き直す。**
いまの座標はカメラ A のこの構図に合わせてある。

## 直し方の順序（実測 2026-08-15/16）

1. **片側だけ暗い / コントラストが違う** → プロンプトの問題。種から post を抜き、
   左右で指示を分けるのをやめる。実測で 0.644/1.000 → 1.000/1.000 になった
2. **全体が一様にずれている** → ここで初めて倍率で合わせてよい。**オフセットは足さない**
   （黒が浮いて「薄い」画になる。gain 0.94 + offset +55 で最暗部が 40 → 73 に浮いた）
3. **絶対的な明るさをプロンプトで狙わない** → 数字で頼むと 0.64 → 0.88 → 1.75 と振れる

⚠ **cue の `hasMatch` / `matchGain` には入れない。** あそこは卓が `bakeColorMatch` で書く場所で、
素材を保存し直すと消える。直すなら画像へ焼き、生の生成物は `_raw.png` で残す。
