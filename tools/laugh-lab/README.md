# 笑い声の調整台

人形の笑いを**鳴らしっぱなし**にして、高さ・声色・速さ・音量をつまみで動かす台。
つまみを動かすと **1〜2 秒で組み直し、鳴っている輪を止めないまま入れ替わる**（0.35 秒で渡す）。

```powershell
.\tools\laugh-lab\serve.ps1        # → http://localhost:8130/
```

⚠⚠ **卓サーバ（`tools/web-compositor/`・8099）とは別物。**
`show.json` も実機も一切触らない。読むのは笑いの種 1 本、書くのは `chosen.json` だけ。

## つまみ

| つまみ | 何 | 目安 |
|---|---|---|
| **高さ** | 素材の何倍の高さで鳴らすか（`LAUGH_PITCH`） | 焼いてあるのは **0.80**（呼びかけの 1.8 倍）。素材は呼びかけの 2.22 倍 |
| **声色** | 声色（フォルマント）をどれだけ元へ戻すか 0..1 | 1 = 同じ女の子のまま ／ 0 = 体格の違う別人 |
| **速さ** | 高さを変えずに笑い方だけ速く／ゆっくり（`LAUGH_SPEED`） | 焼いてあるのは **0.79**。下げると笑いが重なる ⇒ **在音率**を見る（100% は笑いっぱなし） |
| **音量** | 焼くときの狙い（一人 -36.5 / 群れ -30.5 LUFS）からのずれ | 天井 -3dBTP には自動で当たる |

⚠⚠ **音量は「背景を敷く」を押した状態で決める**（既定 ON）。劇伴と装置の声を
実機と同じ音量で下に敷く。**無音の上で決めると埋もれる** — 2026-08-23 に実際にそうなった
（`canon/LEDGER.md` 0118）。
⚠ **数値（基音・LUFS・在音率）は背景を混ぜる前の笑いだけの値。** 背景こみにすると読めなくなる。

⚠⚠ **敷く劇伴は卓（8099）から取る。** 人形が笑う 3 周目以降に鳴っているのは
`HorrBGM` とは限らない（2026-08-23 から 2 周目 C で `LostPlace2` へ渡る）。
**卓が動いていれば実際に鳴っている曲と音量**を、居なければ `HorrBGM` を敷く。
どちらを敷いたかは画面の「劇伴:」と起動時の出力に出る。
⚠ **卓は読むだけ**（GET /state）。`show.json` を書かない・卓を再起動しない。

⚠ **埋もれ方は「生の音量」では分からない。** 内蔵スピーカーは 200Hz より下を返さないので、
低い方に正体がある曲は**生では大きいのに耳では小さい**（`LostPlace2` は -11.6dB 落ちる）。
比べるなら**内蔵スピーカーを通した後・笑いの帯域（250〜4kHz）**で見る。
実測（2026-08-23）: その帯域では `HorrBGM@0.50` と `LostPlace2@0.57` の差は **0.4dB** しかなく、
一人ぶんの笑いはどちらに対しても **-4.3〜-4.7dB**、群れは **+6.0〜+6.4dB**。

**層**は焼いている 4 本そのもの（一人 / 増える 2 体 / 増える 4 体 / 3 枚重ね / 群れ）。

## 決まった値をどう焼くか

「この値を採用」を押すと `tools/laugh-lab/chosen.json`（git 管理外）に残る。
**ソースは書き換わらない** — ブラウザから追跡下のファイルを触らないため。焼くのは人の手で:

1. `tools/ingest-sounds.py` の `LAUGH_PITCH` / `LAUGH_SPEED` を採用値へ直し、
   音量のずれは `SWELL_SOLO_LUFS` と `CHORUS` の狙いへ足す（**この 4 数字で全部**）
2. `py -3.11 tools/ingest-sounds.py --only bed_doll_one bed_dolls_grow_a bed_dolls_grow_b bed_dolls_laugh`
3. `py -3.11 tools/sound-pitch.py` で基音を確かめる
4. `.\tools\unity.ps1 menu sound-import` → ビルド

⚠ **声色だけは 1 数字になっていない**（`pitch_down` の `formant` 引数）。
いまは 1.0 が焼かれている。1.0 以外を採用したら `laugh_source` の呼び方を直す。

## 作りの決めごと

- ⚠⚠ **音を作るコードをここに書かない。** 組むのは `tools/ingest-sounds.py` の関数そのもの
  （`laugh_source` / `ring_mix` / `SWELL_*` / `CHORUS_VOICES`）。別実装にすると、
  卓と実機が食い違った 5 件（`memory/sim_device_divergence.md`）と同じ形で
  **「台では良かったのに焼いたら違う」**が起きる
- **重いのは素材 1 本を作る所**（高さ・声色・速さ）なので、そこだけ覚えておく。
  層と音量だけ変えたときは組み直しだけで済む
- **尖頭は近道で測る**（`true_peak_fast`）。31 秒の輪を丸ごと 4 倍へ伸ばすと 1.0 秒かかり、
  つまみを動かすたびに払うことになる。上位 1.5dB の標本の周りだけ厳密に測れば
  **差 0.02dB 以内**で 20 分の 1（実測）。⚠ **焼くときは使わない**
- **位相を保って渡す。** 同じ長さの輪へ入れ替えるときは、いま鳴っている位置から続ける
  （頭出しし直すと「切り替わった」ことが分かってしまう）
