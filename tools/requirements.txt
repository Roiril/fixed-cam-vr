# Python dependencies for the verification tools (install into py -3.11).
#
#   py -3.11 -m pip install -r tools/requirements.txt
#
# Keep this file ASCII only. pip reads it with the locale encoding (cp932 on
# this PC), so a single non-ASCII character makes `-r` fail with
# UnicodeDecodeError and nothing gets installed (measured 2026-08-10).
#
# Without these, tools/quest-record.py, tools/virtualwalk-video.py and the
# preview/sound tools stop at import. Reinstall after changing PC or Python.
#
# Always call `py -3.11`. The bare `python` on PATH is the Microsoft Store
# stub: it does not fail and does not print a version
# (~/.claude/rules/windows-env.md section 8).
