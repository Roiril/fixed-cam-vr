# 12px の境界拘束

成果物は `G:/マイドライブ/shubie/reports/2026-11-01_screen-effect-study/revision-02/spatial/pinned/`。入口は `spatial-pinned-preview.html`。拘束なしの診断比較は隣の `../spatial-preview.html`。

元のrenderer.js・geometry.js・assets.js・既存出力は変更していない。新moduleはrenderer-pinned.js。APIは同じcreateSpatialScene、diagnosticへweightを追加した。

元の面IDマップの全境界と写真外周から距離を求め、0→12pxをsmoothstepで0→1へ変える。頂点の元カメラ投影座標からこの値を読み、世界空間の変位Fへ掛ける。画素の貼り戻し・背景の穴埋めはない。境界から十分離れた面内では元と同じXYZの変位場が残る。最初の12pxを選び、8pxとの追加比較はしていない。

仮物体の輪郭付近を固定する制約がある。この候補は全ID境界を拘束するため、床と仕切りの既知の接合も抑制される。実物形状の復元ではない。

3.2秒の穴は17098pxから2259pxへ減少。うち外周12pxの中は2083px、内側は176px。8.5秒は1497px（内側138px）、10.5秒は519px（内側147px）。目で見える水平の裂けとフレーム外周の太い穴はほぼ消えた。フレーム上部・縦線付近には細い欠けが残る。床の写真外周には粗い三角形の補間による欠けが残る。外周の数値と主絵の欠落は分けて評価する。

各面3点の可視内部点（元の重み0.75以上）の相似変換を除いたRMSは8時刻で4.78–9.44px。3.2秒の直線からの最大曲がりは床7.57px、仕切りw1 4.96px、w2 2.97px、仮フレーム8.37px、仮棚0.557px。描かれた面の色画素数と軌跡をverification.jsonへ保存した。

ゼロ変形はMAE0.04034、max1、coverage99.99935%。none/local0と時刻を戻したPNGはbyte一致。境界拘束の元の平均重みは床0.897、w1 0.479、w2 0.693、仮フレーム0.451、仮棚0.821。変形を全部ゼロにはしていない。
