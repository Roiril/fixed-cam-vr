# B専用・手動指定の試作

pass02の保護maskだけの変更とは別方式。固定Bの元画像と原寸の縦境界を見て、表示したgradient最大位置を参考にregions.jsonの中心点列を手で置いた。壁と板の間の縦境界、および黒い衣類の左側境界の2本だけを選んだ。任意入力への汎用処理や意味的な線の自動認識とは扱わない。

元のraw RGBへ、選択した境界の左右10px以内で横方向sigma1.4のぼかし由来の輝度差分×.4と参照scalar残差×.85を加え、差分を±.16に制限した。縦方向のぼかしは使わない。コードと金属フレームをpolygon/polylineで保護し、床はy630以降を全て保護した。CRT開口とガラスは対象範囲の外。

Bfull、元と新しいnativevertical/nativecable/nativefloor、手動maskのfull/nativevertical overlayを実際に開いた。主たる縦境界は511行中511行で実際にRGBが変わり、最長連続spanも511行。二本目は271/271行で連続271行。全変更12195px、可視1.284%、全可視RGB RMS1.464 byte。主境界の横のほつれが上から下まで連続している。コードと床の原寸比較はRGBA完全一致。

合成検査は手動保護maskを正しく与えたときの契約だけを調べた。水平・垂直・斜め・交差線の既知の線と周囲2pxを手で保護し、そこは完全一致する。範囲外・OFF・alpha・hiddenRGB・開口内側2px・再計算一致も実画像で検証した。線を自動で発見した証明ではない。

固定Bの範囲と加工の採否は未判定。A/Cには適用していない。ブラウザボタンの操作は未検証。本編・設定・動画は変更していない。
