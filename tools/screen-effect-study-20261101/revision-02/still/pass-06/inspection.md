# pass06・B専用のsemantic mask試作

実物を出す前に、rawのコードとカーペットの原寸へ座標を添えて開いた。コードと曲がったhanger、白い金属フレームを手描きpolylineでなぞった。coreは幅18px、周囲12pxで同じ画素の加工差分だけを減衰させる。床は実際のカーペットの斜めの輪郭に沿うpolygon。旧05のnativecable矩形とy630以降全域のfloorは使わない。意味を機械で認識する処理ではない。

無地の左板は水平の板境界をまたがない上部・下部の内部を選んだ。開口、縦の板境界、横の継ぎ目、カーペットから20px以上離した。ここだけLUT入力をGsigma2+.4×(L−Gsigma2)へ変え、unsharpを止めた。領域の内側20pxで移行する。元画素を平均画像へ丸ごと置き換えず、他の範囲の細部や境界をぼかしていない。

縦境界のsupport半径は10から18pxへ尺度補正した。参照active幅1440に対するB開口約1110〜1120の比から、参照半幅24pxに対応するB半幅は約18.5px。atlas[-24,24]を半幅18pxへ対応させた。gain、横blur sigma、delta上限は04のまま。新しい明暗や新しいnoiseは加えていない。

raw/04/05/06のfullと原寸wire/floor/vertical/左板上下/right/旧core下端/カーペット境界を開いた。05の暗い矩形と左白板を横切る水平の明暗帯は見られなくなった。カーペットの保持境界は実物の斜めの境界に沿う。コードの周囲も長方形の画面切替になっていない。手動無地領域の周辺には粒密度の緩やかな移行があり、板の全域を一様に整えたわけではない。保護外の黒い衣類と天井の粒や黒つぶれは04のまま残る。

主境界511/511行、衣類左271/271行、右布146/146行で実spatial変化が連続する。コードcoreとカーペットcoreはraw RGBA完全一致。4閾値のdark maskと連結数もcore内で一致する。3断面はcontrast .142190/.017362/.140008、暗部FWHM10.25/17/16.25pxでrawと一致。これらの断面は周囲も含む値であり、線だけの物理的幅の推定ではない。図の青い帯でraw保持coreの範囲を分けて示した。実coreの画素完全一致と、周囲を含む断面値を区別する。

左板の高周波RMSは04比で上.519、下.446。raw比では上.670、下.983。カーペットはraw比1.000。コードを含む大きいROIは周囲の衣類・背景も残るためraw比1.834で、線coreだけの指標とは扱わない。04→06差分はsurface範囲・semantic保護と移行・半径18pxの縦加工範囲の和の外で0画素。OFF、alpha、hiddenRGB、内側2px、repeatも一致した。

surfacegrain、線保護、縦residualは別々の差分PNG/NPZへ保存した。旧pass01〜05の凍結SHAは不変。採否は未判定。指定の1候補だけを作り、追加探索はしていない。本編やA/Cへは適用していない。ブラウザのボタン操作は未検証。
