# pass07・B専用の1候補

原寸の板面へpolygonを重ねて開いてから2面を固定した。上の板と下の板の実際の面に沿い、glassと広い輪郭を含めず20pxの内側移行を置いた。内部はGsigma4+.10×(L−Gsigma4)をLUTへ渡し、unsharpを使わない。広い画面全体や輪郭やコードを平均画像へ置き換える処理ではない。

コードとカーペットは06の手描き形をそのまま使う。コードcoreにはrawL+1.0×(rawL−Gsigma.9)、カーペットcoreにはrawL+.75×(rawL−Gsigma1.1)の共通luma差分だけをrawRGBへ加える。LUTは通さない。周囲12pxは06と同じ距離smoothstep。コードRGBがrawと完全一致するという06の主張は引き継がない。

縦support18、gain、blur sigma、3本のpathを変更していない。06のspatialdelta配列との完全一致を直接確認した。黒い物体の弱い筋には新しい操作を加えていない。

raw/04/06/07のfull、原寸board上下/cable/floor/vertical/carpet移行/板の境界を開いた。板の粗い反復粒は06より減った。細かな粒が残るglass寄りの帯と、低周波の明暗は残る。コードは04の黒つぶれへ戻らず、元の線の形が見える。床の線は06より少し強くなる。原寸で新しい切断や広い白haloは見つけていないが、数値だけで接続の完全保持とは扱わない。05の大きい矩形と水平の帯は戻っていない。

板の高周波RMSは06比で上.388/下.277。raw比では.260/.273。カーペットはraw比1.205。主境界511/511行、衣類左271/271行、右布146/146行の連続coverageは維持する。

実コード3断面のcontrast比は1.064/1.333/1.014。暗部FWHMは10.25→10.75px、17→17px、16.25→16.25px。最初の断面の+.5pxを隠さず残した。近傍を含む断面なので線だけの物理的な幅とは同一視しない。断面図で手描きcoreを青く分けた。断面内の明部最大値/暗部最小値もmanifestへ記録した。

4閾値のcore内連結数は41→50、7→13、9→11、8→11。dark pixel数と閾値をまたぐ画素数も記録した。unsharpで細部やnoiseが閾値をまたぐため、成分数の増加だけを実コードの切断数とは解釈しない。旧06のdark mask完全一致は主張しない。コードとカーペットのcore内gamutclipは各0px。

合成2/4/6/12px、水平/垂直/斜め、明暗24形をコード/床の2種の固定unsharpへ通した。FWHM増大は0pxだったが、実画像で+.5pxが出た結果を合成fixtureで上書きしない。OFF、alpha、hiddenRGB、内側2px、repeat、指定範囲外0画素、縦delta不変、各coreが指定LUT無しtargetと完全一致することを検証した。

板面、コード、床、縦deltaを別の差分PNGへ保存した。旧01〜06の凍結SHAは不変。1候補だけで追加探索はしていない。黒い物体の筋が沈む点は未達の可能性として残す。採否は未判定。本編やA/Cへは適用していない。ブラウザ操作は未検証。
