# pass08・中央の1本だけ

参照スクショの白窓縁の原寸を再度開いた。縁に細かい横片があり、同じ幅と白さの長い帯には見えない。今回はwall-board-vertical（およそx630〜640）の1本だけを対象にした。中央の他の衣類左境界と右布境界は変えない。

support半径18→12pxを唯一の幅設定とした。18px全体の外側1/3を残すより、横の細片を境界近くへ収める意図。既存atlas[-24,24]を±12pxへ対応させる。scalar residualは同じ参照由来のもの、同じgain .85、同じ行位相で加える。参照の写真やRGBは移植していない。

連続したblur base deltaだけを行単位で間引いた。参照scalar atlasの49サンプル中max(abs(residual))を行の局所強度とする。中央値.4212748以下はblur delta0。中央値から参照最大.75へ連続して0→1にする。scalar residual自体はこのgateを掛けず残す。これは一度固定したデータ由来の規則で、係数探索や別案の選別はしていない。blur sigma1.4、blur gain .4、scalar gain .85、cap .16は07と同じ。

511行のうちblur baseが0になるのは259行、残る252行は参照強度に応じた値。scalarを含む最終中央deltaは508行で実在し、最長連続span391行。したがって中央delta全体が半分の行で消えたとは言わない。07との差は14054px、中央の既定のsupportの外は0px。

raw/07/08のfullと原寸vertical/central/cable/floor/board、および07→08差分を開いた。中央の横への広がりは少し狭まり、細片は境界近くに残る。全体の見えの差は局所的で、大きい白黒のまとまりは07のまま。短い横筋への見えの採否は未判定。追加の調整はしていない。

07をソースから再計算し、凍結したRGBAと完全一致することを先に確認した。中央の元supportの外、板面上下、コード、床、他2本の縦境界の各ROIは07とRGBA完全一致。surfacebase、コードtarget、床targetも同一。OFF、alpha、hiddenRGB、内側2px、repeatは一致。旧01〜07の全凍結SHAは不変。本編や他chatは変更していない。
