# 追加加工・2版目

1版目は `round-01/` に保存した。従来の `still-default.png` と `preview.html` も残している。2版目は `round-02-` で始まる別ファイルへ保存した。

## 受け取った比較結果

親エージェントから独立比較結果の要約を受け取った。実装説明なしの実画像2枚で48%。輪郭57、粒30、暗部69、明部43、崩れ41。これは評価者の主観的な点数であり、画像の物理的な測定値ではない。わたし自身が採点したものではない。

指摘は「候補は細かく均質な横毛羽立ち、面全体の細粒と斜め擦れが目立つ。参照は鋭い白黒境界ともっと長い横筋が輪郭/細部に集中。候補は中間灰色/灰色粒が多い。形は保つが不揃い行ずれと欠け不足」。これは親経由で受け取った要約であり、ユーザーの発話としては扱わない。

## 2版目で変えた処理

- 全面へ足すランダム粒を除いた。
- 暗部とハイライトに平坦な部分を持つ輝度曲線を使った。暗い面では階調が黒へまとまり、明るい面では白へまとまる。
- 広い範囲の輝度差を使って輪郭の局所的な明暗を強めた。
- 4〜15画素の長さを持つ横方向の延長と欠けを疎らに足した。輪郭の近くだけに掛ける。
- ずれない行、小さくずれる行、大きくずれる行を混ぜた。全行を同じように細かく乱す処理を止めた。

ベースは初版と同じ `base.png`。元PNGにある斜めのにじみとCRT加工はそのまま入力として読む。曲面の形とalphaは変更しない。青い色相と参照のキャラと参照画素は使用しない。

## 出力と比較

`round-02-default.png` がRGBA候補。`round-02-default-on-black.png` が独立比較用の不透明画像。追加前後は `round-02-comparison-full.png`。同座標の切り出しは `round-02-comparison-curtain.png` と `round-02-comparison-rail.png` と `round-02-comparison-shadow.png`。

`round-02-preview.html` は独立した自己完結の調整画面。元の初版画面は上書きしていない。2版目の「横筋の密度」は全面の粒を増やすつまみではなく、輪郭に限定した横筋の出現率を変える。種は固定している。

元画像と2版目の両方を画像ビューアで開いた。alpha最大差0、全透明画素のRGBA最大差0、OFF時最大差0、同じ値で再計算した最大差0。結果は `round-02-processing.json` に保存した。

ブラウザの実表示は初版と同じく未検証。`file://` の自動表示がURL policyに拒否された後、代替経路で回避していない。本編Unityは変更していない。2版目の独立評価と採用判断はここには含まない。
