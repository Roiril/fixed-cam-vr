# 追加加工・4版目：参照由来の変位と輝度残差

3版目の新規独立評価は57%。輪郭71、不規則53、粒45、明暗60、崩れ54。指摘は「筋が細かく均等、中間面の粒が広い、局所的な横流れ/輪郭から離れた断片少ない」。親経由で受け取った評価要約であり、ユーザーの発話ではない。点数は評価者の主観的判断。以前の画像と記録は残している。

4版目は参照から測った行ごとの変位と無次元の輝度残差を使う。疑似乱数で作った行列へ戻して強弱を調節する方式を止めた。出力には `ref_derived: true` と記録した。

## 測定の出所

元参照は `C:/Users/kouga/Downloads/Screenshot_20261101-004612.png`。ROIは原寸の `[880,20,970,300]`。窓の左端の縦の境界を含む。ROIの切り出しは診断用に `round-04-reference-edge-roi.png` として保存した。これを候補画像へ貼り付けてはいない。

Pillowの `convert('L') /255` で輝度だけを読む。各行で0.72より明るい画素が6画素連続する最初の位置を検出した。検出位置はx894〜927。行番号に対する2次の最小二乗曲線を引き、大きな傾きと形を取り除いた。

残った水平変位の標準偏差は4.43px。5〜95パーセンタイルは−8.65〜+5.97px。最小−12.79px、最大+19.75px。行ごとの値を280点のlookupとしてそのまま保存した。候補では画面幅の差に応じて0.78倍して使う。

## 横筋の残差

検出した縦枠に位置を合わせ、左右32画素の輝度を調べた。ROI全行の左10列と右10列のmedianを使い、左右の明暗差を1として正規化した。その後、同じoffsetにある全行のmedianを引いた。値は±0.5に収める。

この処理で残るのは、同じ境界の平均的な形から各行がどれだけ明暗方向に乱れたかという数値。元のRGBと絶対輝度は候補へ渡さない。参照の室内やキャラの形を描く素材としても使わない。

残差の絶対値0.08以上が続く区間も記録した。区間の長さはmedian4px、90パーセンタイル14px、最大32px。各行で長さと出現位置が異なる。lookupには変位と残差とrunの長さを保存した。出所のhashとROIと式も同じJSONにある。

## ベースへの適用

処理入力は固定した `base.png` と `base.rgba`。元の更新されるPNGパスを読まない。元PNGのhashと固定コピーの一致、固定コピーから再デコードしたRGBAと処理入力の生RGBAの一致を必須にした。

ベースの縦の境界を行ごとに検出する。大きな明暗差のある境界から左右32pxの範囲だけへlookupを適用する。変位で近くの元画素を読み、輝度残差は候補側の局所的な明暗差と極性に合わせて加える。輪郭のない暗い面へ独立した白い粒を発生させない。

面の階調曲線は3版目と同じ。白黒面積を参照へ合わせる処理は行わない。元ベースの粒の整理は、5×5 bilateralから半径7px・epsilon0.06²のguided filterへ替えた。平均と分散から平らな面を整え、大きな明暗差を保つ。元PNGにある大きな斜めのぼけは復元していない。
