# 追加加工・10版目：9-Aの光学処理を固定して局所的に欠かす

9版目の同一評価者による比較はA67、B63、D65。Aが選ばれた。内訳は輪郭73、面内63、粒57、明暗72、不規則68。親から受け取った評価要約であり、ユーザー発話ではない。

最大の差は、同じ高さで広く横揺れすること、平坦面の周期模様、連続した輪郭の毛羽立ち。10版目は光学処理を変えず、平坦面の整理と局所的な欠けへ変更した。9版目の出力ファイルは上書きしていない。

## 光学段の固定

固定baseから9-AのNLMとWiener処理を再実行し、保存済みの `round-09-A-optical-stage.png` と画素が完全に一致することを必須にした。元の更新される入力パスは使わない。光学段のhashと再生成一致を10版manifestへ記録した。

9-Aの光学段はGaussian PSFを仮定した処理であり、元の光学系の正解を同定したものではない。その仮定は今回増やしていない。

## 平坦面だけをさらに整理

NLMの強さ8と境界保持フィルタを使い、平坦な面だけ追加で混ぜる。絶対標準偏差だけでは暗い床の構造まで平坦と誤判定するため、局所平均に対する相対的な標準偏差も条件にした。暗い床でも相対的な明暗差が大きければ9-Aの細部を保つ方向へ寄せる。

自己目視では左の壁の粒と周期的な模様が減り、平坦な面として残る。元画像の斜めのぼけを復元する処理ではない。

## 行全体を動かさない

全域の行shiftと全行全域のechoは撤去した。入力の勾配と細部のエネルギーから、効果が出る場所を選ぶ。位置は規則グリッドに揃えず、重み付きの独立した座標へ置く。

1つの場所に2〜4個の小さい欠けを群として作る。高さは1〜3px。長さは参照から測ったrunを2〜12pxへ使い、約7%のeventでは16〜32pxを混ぜる。変位は参照の実測値から選び、元の近傍へ局所的に読み替える。これにより輪郭の連続を部分的に欠く。全透明域のRGBを読み替え元へ使わない。

## 密度と水平の芯が違う3候補

- Aは1700群。局所faultのmaskが可視画面へ掛かる割合は4.28%。
- Bは4200群。同割合8.81%。
- Cは2800群。同割合6.42%。Dで使った上下差分と横相関の細部を25%だけ混ぜる。

この割合はfaultの配置maskの面積であり、参照へ合わせる目標値ではない。独立評価の類似度でもない。

## 実画像での確認

元参照全体とA/B/Cの全体を実際に開いた。床と平坦面も原寸の追加前後で開いた。同じ高さの全域の揺れがなく、平坦面の周期模様が減ったことを確認した。欠けは構造の近くへ集中する。

自分の観察では、Cを先に見る候補とし、Bをfault密度の比較に残す。輪郭の局所的な欠けが増えたことと、参照へ近づいたことは分ける。独立採点と採用判断は未実施。

生成目標画のRGBと固定補正fieldは使わない。参照から使うのは数値lookupのrun分布と変位だけ。入力画素は固定baseからのフィルタ計算で得る。
