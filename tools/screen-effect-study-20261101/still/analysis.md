# 参照静止画から観察した追加加工

参照: `C:/Users/kouga/Downloads/Screenshot_20261101-004612.png`。実際に画像を開いて観察した。画中のキャラと青い色相を再現対象から外した。元画像の画素は試作へ流用していない。

## 空間方向

窓の縦枠やモニターの縁では、輪郭が細かな横線へほどけている。縦線が均一な線として続かず、行ごとに短く左右へ飛び出す。画面全体が一定の幅で横へずれる形とは異なる。物の境界で目立つ。

机や床の線には明るい線と黒い線が近接している。輪郭の片側へ細い明暗が重なり、一本の線に見える場所と複線に見える場所がある。大きなRGBの色ずれだけでは説明できない。

## 細かさ

粒は等方的な丸い点より、横へ短く続く筋に見える。大きなぼかしの上に細かい乱れがある。輪郭の位置は数画素単位で乱れる一方、物の大きな形は読める。単に低解像度へ落としたブロック状の形とは異なる。

細部は一様に残っていない。床の線は細かく強く出るが、暗いモニターの面では内部の差が減る。面の内部と境界を同じ量だけ乱すと、この違いを失う。

## 明暗

明るい窓は内部の差が少なく、白い面としてまとまる。暗いモニターや椅子の影も黒い面としてまとまる。その間の輪郭と中間の明るさでは細かい差が強く見える。画面全体へ同じ振幅の粒を置くと、黒い面がざわついて観察と変わる。

明暗の変化は強いが、全てを二値化した画像ではない。椅子や壁には滑らかな明るさの変化が残っている。試作でも連続した明暗を維持し、暗部の明るさを連続曲線で下げた。

## 色と画面の形

青い色相は適用していない。処理では元のRGBへ共通の倍率を掛けて明るさを変える。ハイライトのクリップと横方向の再サンプルで局所的な色の比は変わり得るが、指定した青への色置換は行わない。

参照に映った部屋の形とキャラは使わない。既存CRTの曲面やガラスや色の処理はベースPNGへ既に含まれている。追加試作では湾曲とビネットと走査線を二重に足していない。

## この試作に入れた処理

- 輪郭で強くなる行ごとの短い横ずれ。初回値では行の基準変位はおよそ±3画素。
- 輝度の横方向の差から作る明暗の細い複線。色チャンネルの位置は別々にずらさない。
- 3画素ほど横へまとまる粒と1画素単位の粒の混合。輪郭と中間の明るさで振幅を上げる。
- 元の色を使った明暗の拡大。暗部を連続曲線でまとめる。

これらは1枚から読み取った加工感に対応する試作であり、実際の信号障害や使用ソフトを同定したものではない。時間方向の揺れと点滅と粒の更新速度は静止画からは確定できない。今回のUIは粒の種を固定し、強さの比較で時間変動を混ぜない。
