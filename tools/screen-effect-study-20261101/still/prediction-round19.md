# 19版目の見た目予測

元の採用描画を入力にし、旧試作の加工画像を一切使わない。NLMとbilateralで連続した中間面を残す。細かな陰影は20%だけ戻すため、床の灰色の面も残る見込み。黒い物体へ白い粒を描く処理は無い。

行の大半は動かさず、4〜12行の静止の間に1〜3行だけ±1〜3pxを動かす。輪郭が同じ行で一緒にずれる一方、14版目のように全輪郭へ独立した糸を放出する形にはならない見込み。±15px以上の裂けは発生しない。

水平2〜4pxの片側リンギングは局所明暗差>.08の境界だけに加える。上限は局所明暗差の25%。広い壁に新規の縞や粒を作らず、輪郭の明暗の返しが弱く見えると予測する。白黒のコントラストを別途拡大しないため、14strongより写真由来の中間調が多く残る可能性がある。

面S単独と最終像を別々に開く。定数面、斜め境界、細線の3入力で、平坦面の模様0、変位量、中間灰色の残存を検証する。alpha外RGBは計算前に有効色で延長する。alphaとhiddenRGBと開口最内2pxを元のまま保存する。
