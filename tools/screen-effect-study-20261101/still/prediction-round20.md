# 20版目の予測

14strongの方式を元の採用描画から再計算する。19版目の面Sも同じ元入力から計算する。14strongの細い横裂けと白黒の擦れは高周波成分として残し、面Sから幅3px以上の低周波だけを補う。

補う場所は入力の細部がある領域に限る。19の面の局所分散が低い広い壁と黒い面は保護する。14で低周波の灰色が下がっているところへ正の補正だけを戻す。補正場もGaussian幅3pxで滑らかにし、新しい短片や高周波は描かない。

床の擦れの間に灰色の面が増え、14strongの線自体は19単独より多く残ると予測する。白黒線の明暗差は低周波を足した際のクリッピングで弱まる可能性があるため、高周波の投影係数とクリップ率を測る。0.25/0.5/0.75の3段階を同じBと他の採用入力へ適用する。元alpha、hiddenRGB、開口最内2px、OFFを維持する。
