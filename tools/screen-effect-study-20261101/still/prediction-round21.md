# 21版目の予測

元Bを内部だけ.75/.60/.50の等方的な画素間隔へarea縮小し、14型処理の空間パラメータはworking画素単位に保つ。14の追加群は5200×scale²、12の局所欠けの群も4200×scale²へ減らす。同じ全画面へ戻した際に、短片の幅と長さと群の空白が一緒に大きくなる見込み。

15のように固定の明るい値や不透明度へ変えない。14strongの局所明暗と不透明度を使い、20の灰色の低周波補正は加えない。結果RGBはbilinearで元の座標へ戻すため、nearestによる正方形のピクセル模様を避ける。

小さい格子ほど輪郭の細かな写真陰影も減り、横擦れが太く見える一方で、細部の像が丸くなる可能性がある。全体と床・輪郭・平坦面を原寸で比較して確認する。最終1280×1030の外形と画角、alpha、hiddenRGB、開口最内2pxは元Bから保護する。
