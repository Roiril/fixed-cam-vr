# 22版目の予測

native解像度で14strongの大きな明暗と平坦面を残し、独立した短片を水平線の局所束へ置き換える。束ごとに方向、明暗、長さを揃え、3〜6本の1px線を間隔を空けて置く。各線の始点は小さな累積段差だけを持つ。子ごとの独立したx/y/極性の散らし方をやめる。

局所high/lowと不透明度.65は14と同じ。芯を固定の白へ置換しない。長さは短い横線を主体にし、16〜24pxの長い束は1%だけにする。線の中央は安定させ、端だけ弱める。線間に空白を残すため高さを1pxに保つ。

画像上の差分で水平相関、成分の幅、小さな点と太い片の比率を測る。14より線の横連結が伸び、点状の細片が減ると予測する。全体の平行縞にならないか、同じ2設定をA/B/Cへ適用して全体と原寸で確認する。自己採点はしない。
