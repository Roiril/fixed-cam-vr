# 23版目の予測

元スクショの窓左右とモニタの縁から、行の暗部・明部を正規化した輪郭残差を抽出する。基準形はmain edgeのロバストな二次曲線。理想blur stepとの差を49列の2D scalar residualとして使う。これは加工と元形状の完全分離ではなく、特にモニタの反射と幅が残る可能性がある。

現入力の縦と穏やかな斜め境界を検出し、局所法線の座標とコントラストへ残差を対応させる。色や窓の画面座標は使わない。輪郭ごとに異なる位相、並び、伸縮を使い、同じ模様を同じ高さへ敷き詰めない。22の独立短片の描画は使わず、12段階の大きな階調と14の薄い微小信号を保つ。

細い単独の線より、にじみと複線の混じった局所的な縁になると予測する。一方で残差に含まれる元の形や反射が別の物体の縁へ不自然に見える可能性がある。atlas全点、向きと明暗の異なるsynthetic、実画像全体と原寸を開き、窓の形や反復模様が残っていないかを確認する。自己採点はしない。
