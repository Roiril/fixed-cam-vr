# 26版目の予測

古いfaultを弱めると独立評価が下がった25の結果を受け、矩形置換1.0のgross12を戻す。23のtrackと参照残差、法線幅1.25、接線pitch1.00は固定する。

残差を鋭い現輪郭へ加算する方式から、理想step sigma3と参照残差で波形を再構成し、現在stageの行ごとの両側中央値へ暗明を対応させる方式へ変える。輪郭の帯内は混合.65/.85/1.0。中心の帯はfullmixで現輪郭を二重に残さず置換し、u18〜24で外側へ弱める。帯外の既存faultは維持する。

灰色の二重縁と鋭い小片が弱まり、参照の重なった線とにじみが波形として現れると予測する。反面、両側の測定に隣の形が混ざると明暗を取り違える可能性があり、低contrast・開口近傍を保護する。自己採点なし。
