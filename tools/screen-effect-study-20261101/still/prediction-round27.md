# 27版目の予測

26softの置換量.65とgross12/fault1を保ち、波形を対応させてよい境界の信頼度を求める。plateauの局所分散、明暗差、別edgeまでの距離を使う。隣の物が測定へ混ざる細いshadowやcurtain ribでは置換を弱め、孤立したstepへは効果を残す。

Aは26softに信頼度だけを加える。Bは同じ信頼度でsource行と最終Y座標を整数へ対応させ、Xはcubic、法線幅.90で細い行を保つ。CはBの波形contrastを1.25へ上げる。全体の階調曲線は変えない。

灰色帯の副作用を減らしながら、孤立した強い境界では細い横線の重なりと白黒芯を残せると予測する。信頼度で加工を消しただけになっていないか、適用面積と高信頼度領域の差分を測り原寸で見る。自己採点なし。
