## 描画前の予測（変更しない）

賭け: 丸いガラスの縁と暗色筐体を別々に比較すれば、映像の加工と装置の存在感を選び分けられるはず。

- 同じ加工で筐体を足した組は、映像の縦横比を保ったまま中央像が縮む。
- 強い版では明暗境界の色ずれとガラス縁の反射が控えめな版より見える。
- 走査線・追加の時間ノイズを使わずに、現行との差を静止画で確認できる。

形状の基準（16:9、曲面の膨らみ0.055）と撮影条件は全案共通。

無人写真は640×480の4:3のままcontain-fit。細かな反射は設計案であり実機の測定ではない。
静止画なので追従、時間変化、両眼、Quest上の負荷と怖さは未検証。

## 確認結果

- 元写真のSHA-256が撮影元と一致。全20枚が1920×1080。欠損・単色・シェーダエラー色なし。
- 各カメラの現行と4案は異なるハッシュ。全PNGを個別に目視した。
- 独立したheadless Edgeで12通りのカメラ・比較案の切替とAの斜め表示を確認。
  B/Cへ替えると正面へ戻る。スライダーと画像拡大も動作。
- 1280px/375px × light/darkの4条件で横はみ出しなし。全画像読込成功、実行時エラーなし。
- `qa/` にブラウザのスクショ8枚と `browser-check.json` を保存。
- 予測との差: 参照にある4:3装置の外形は試していない。16:9を維持したため、筐体は横長で黒帯が残る。
  強弱の差は筐体の有無の差より小さく、一覧の縮小画像だけでは比較しにくい。HTMLの拡大を使う。
