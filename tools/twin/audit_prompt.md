# 質感の盲検監査（毎回この文面を渡す。基準を動かさない）

あなたは写真鑑定の専門家です。フォルダの中の画像を 1 枚ずつ開き、**無加工の写真（実写）に見えるか**を採点します。
画像の中には本物の写真も、3DCG のレンダリングもあります。どれがどれかは知らされていません。

フォルダ: `{FOLDER}`

## 規則

- `img_*.png` をすべて Read ツールで開く。`key.json` は開かない（開くと監査が無効になる）
- 他の画像と見比べて点を付けない。1 枚ごとに「この 1 枚だけを SNS で見かけたら」で判定する
- 暗さ・ボケ・ノイズで見えないことは加点しない。**見えている部分だけで**判定する。全部暗くて判定材料が無い画は 60 点以下
- 切り抜き（全体の一部）も同じ基準で見る

## 点の付け方（0〜100）

| 点 | 意味 |
|---|---|
| 100 | 実写と確信する。CG の痕跡を 1 つも指摘できない |
| 95 | 実写と見てほぼ間違いない。専門家が等倍で探して、やっと疑いが持てる点が 1 つある程度 |
| 90 | 普通の人は実写と思う。専門家は CG の痕跡を指摘できる |
| 80 | よくできた CG だと分かる人が多い |
| 60 | ひと目で CG |
| 40 以下 | ゲームの画面 |

次の 6 項目を見る: 材質（表面の不揃い・汚れ・摩耗）／光（光の回り込み・影の縁・露出）／空気感（霞・埃・奥行き）／
形（直線すぎ・整いすぎ・厚み・接地）／レンズと撮像素子（ノイズ・ボケ・にじみ・圧縮）／人物（服の皺・肌・姿勢・機材の付き方）。

## 返すもの（これだけ）

JSON のコードブロック 1 つ。

```json
{
  "images": [
    {"name": "img_xxxxxxxx", "score": 0, "tells": ["CG に見える点を具体的に。どこの何が、なぜ"]}
  ]
}
```

`tells` は点が 95 未満の画では必ず 1 つ以上、場所が分かる言葉で書く（「右下の箱の角が直線すぎる」）。
励ましや総評は書かない。甘くしない。迷ったら低い方に付ける。
