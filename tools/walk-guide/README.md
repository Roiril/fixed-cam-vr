Blender のヘッドレスで焼く。会場は `tools/web-compositor/show.json` の実データから起こすので、
**現場の寸法が変わったら焼き直すだけで追従する**。

```powershell
& "C:\Program Files\Blender Foundation\Blender 5.1\blender.exe" --background `
    --python tools\walk-guide\build_walk_guide.py
```

|---|---|

## 何を決めているか

| 値 | いま | 出どころ |
|---|---|---|
| 歩く速さ | 0.513 m/s | `ShowWalkDebugDriver.WalkSpeed` = 0.5 m/s に合わせた |
| 1 歩 | 1.05 秒 | ゆっくりだが不自然でない足の運び |
| 1 周 | 5.03 m ／ 9.8 秒 | 壁の形から算出 |
| 手すりの高さ | 0.95 m | — |
| 壁の芯から手すり | 0.08 m | `Joint.blend` の枠の奥行 0.16m と同じ |
| 壁の芯から順路 | 0.24 m | 壁面から 0.22m ＝ 幅 0.4m の通路のまん中 |

## 詰まりやすいところ（実際に踏んだ順）

- **素材の歩きは 1.60 m/s。** そのまま遅回しにすると「大股のスローモーション」になり、
  真似できる速さに見えない。**振りを 1 循環の平均へ寄せて歩幅を 0.82 → 0.54 m に縮めてから**、
  足が滑らない速さで歩かせる。縮めると足が浮くので毎コマ低い方の足を床へ着け直す
- **前を向いている向きを肩の並びから外積で出すと符号を取り違える。** 実際に 180 度ずれ、
  体の反対側へ腕を伸ばしたまま後ろ歩きしていた。**足首から爪先へのベクトル**なら一意に決まる
- **正方形の順路は会場に合わない。** 壁の西の腕は南へ y=-0.72 まで伸びていて、
  中心にそろえた輪だと壁の端に 0.02m まで寄る。順路は**壁のオフセット**にする
- **取り込んだ armature は X 90 度で立っている。** yaw を `rotation_euler` に書くと人が寝る。
  世界の Z 回りの回転を**左から**掛ける。`atan2` は ±π で折り返すので角度は繋いで数える
- **手の向きは IK では決まらない。** 手首の位置しか決まらず、向きは歩きの振りのままになる。
  指を進む向き・手のひらを下へ `COPY_ROTATION` で固定する。どの骨の軸が手のひらかは
  ロールで変わるので、**人差し指と小指の付け根から実測**する（親指との内積で符号を決めるのは駄目。
  親指は横に張り出していて内積がほぼ 0 になり、コマによって反転する）
- **カメラの距離を手で決めると、人が奥の辺に来たコマだけ頭が切れる。** 順路上の頭の高さ・
  床の角・三脚を並べて、どのコマでも収まる最短の距離と見下ろし角を探す
- **字幕の帯の幅を文字数から見積もらない。** 全角と半角で 2 倍ずれて端が白地に溶ける。
  組んだ文字の実寸を測って囲む。帯はカメラの面と平行に置く（立てると横倒しの線になる）
- Blender 5 の `Action` に `.fcurves` は無い（スロット付きになった）。`fcurves_of()` を通す

## 焼くたびに読む数値

`[walk-guide]` の行に出る。とくに次の 3 つ。

- `右手側の一致 1.00` — 前と右が合っているか。0.8 を切ったら腕が体の反対側へ伸びる
- `順路と壁のいちばん近いところ` — 0.18m を切ったら `D_WALK` を大きくする
- `手 手のひらの下向き 1.00 ／ 指と進む向きの一致 1.00` — 手すりへの置き方

## 分かったこと（会場の側）

**壁の西の腕（`show.json` の `w2`・南端 y=-0.72）を回り込む足取りは、床 1.8m 角から 0.06m はみ出す。**
順路を壁から 0.24m 取ると南の折り返しが y=-0.96 まで下がるため。詰めるなら壁を短くするか、
折り返しをその場旋回にする。動画はいまのまま（0.06m）で焼いてある。
