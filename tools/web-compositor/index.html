STEP 2 / 演出

撮影からビルドまで

素材を確定してからビルド

本番の構図と照明が決まったら、会場で必要な素材を撮ります。人形視点はその日の映像を使います。画像や動画を作り直す演出は、会場で撮った写真を元にします。

  1. 1

    会場の画を撮る

    カメラを固定し、本番の照明で無人の画を撮ります。人形視点の 5 本も会場で撮影して採用します。

    人形視点の撮影状況を確認しています。

    人形視点の撮影を開く →
  2. 2

    必要な画像・動画を作る

    現場の写真と合わなくなる演出は、その写真から画像を作ります。動きが必要なら画像から動画にします。動画化した結果は素材工房へ取り込みます。既存素材まで一律に作り直しません。

    素材工房を開く →

    素材の採用には編集を有効にした卓が必要です。

  3. 3

    試写して採用する

    人形視点は実際に画面へ出る冒頭を確認します。生成した素材は配信映像に重ね、位置と明るさを確認してから演出に採用します。

  4. 4

    確定した素材でビルドする

    採用を終えたらビルド用に書き出して APK を作り、Quest α と β の両方へ入れます。撮り直しや差し替えをしたら、ここからやり直します。

ビルドと実機版の照合

ここはファイルと版の確認です。会場の画との一致は試写で判断します。

体験者が博士のチュートリアル画面で選ぶ言語とホラー軽減モードだけです。選択は各 Quest に直接届きます。

STEP 1 / 設営

設置の手順

担当と IP は固定
  1. 1

    会場の Wi-Fi を起動する

    ルーターを起動します。PC の IP は 192.168.10.10 です。カメラと Quest も同じネットワークにつなぎます。

  2. 2

    A・B・C を決まった場所に置く

    スマホ画面の担当と固定 IP を確認します。A は .21。B は .22。C は .23。接続できなくても担当は入れ替えません。

  3. 3

    構図を合わせて明るさを固定する

    本番の照明にします。スマホの設置用画面で超広角と構図を確認します。露出とホワイトバランスを固定します。

  4. 4

    撮影の準備をする

    人形視点を撮るスマホと白衣を用意します。カメラの位置と照明を決めてから「演出」へ進みます。

つながらないときに見る場所

1 台だけ応答しない

該当スマホの電源を確認します。配信アプリを開きます。表示された IP とこの画面の固定 IP を見比べます。

応答はあるが映像が止まる

端末の画面を点けてアプリを開きます。熱とカメラ権限を確認します。「この端末を起こし直す」が使えれば実行します。

複数台が同時につながらない

PC が会場の Wi-Fi につながっているか確認します。ルーターの端末間通信の制限も確認します。Wi-Fi の自動切り替えは行いません。

担当や端末が違うと表示される

別の端末をつかんでいる可能性があります。A・B・C を入れ替えずに設置場所を確認します。端末交換時は保守用の登録を更新します。

状態を残す

不具合が続く場合は確認結果を保存できます。認証情報は含みません。

この画面は点検用です。演出の変更と素材の採用はビルド前に行います。
