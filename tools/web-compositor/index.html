STEP 1 / 設営

設置の手順

担当と IP は固定
  1. 1

    会場の Wi-Fi を起動する

    ルーターを起動します。PC の IP は 192.168.10.10 です。カメラと Quest も同じネットワークにつなぎます。

  2. 2

    A・B・C を決まった場所に置く

    スマホ画面の担当と固定 IP を確認します。A は .21。B は .22。C は .23。接続できなくても担当は入れ替えません。

  3. 3

    構図を合わせて明るさを固定する

    本番の照明にします。スマホの設置用画面で超広角と構図を確認します。露出とホワイトバランスを固定します。

  4. 4

    接続を確認する

    人形視点を撮るスマホと白衣を用意します。「接続」で撮る端末の映像を確認してから撮影を始めます。

つながらないときに見る場所

1 台だけ応答しない

該当スマホの電源を確認します。配信アプリを開きます。表示された IP とこの画面の固定 IP を見比べます。

応答はあるが映像が止まる

端末の画面を点けてアプリを開きます。熱とカメラ権限を確認します。「この端末を起こし直す」が使えれば実行します。

複数台が同時につながらない

PC が会場の Wi-Fi につながっているか確認します。ルーターの端末間通信の制限も確認します。Wi-Fi の自動切り替えは行いません。

担当や端末が違うと表示される

別の端末をつかんでいる可能性があります。A・B・C を入れ替えずに設置場所を確認します。端末交換時は保守用の登録を更新します。
