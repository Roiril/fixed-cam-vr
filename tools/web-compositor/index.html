切替タイミングは入力するとその場で反映（空 / 0 = 未指定 → Unity 既定 0.5s）。歩くと切替が起きない時は下げ、切替が忙しい時は上げる（control.minDwellSec / switchCooldownSec）。
体験の骨格（show.json run）。企画書は「3 区間を 3 周・導入を含め 3 分以内・各周およそ 30 秒」。走り切る周数を回ったあと、元の位置（スタート領域）へ戻ったところで終わるので、タイムラインには「もどり」の区間が 1 つ増える。導入の自動終了は「最低尺を過ぎ、かつスタート区間に居る」の両方が要る（自動を切ればスタッフの ⏭ だけで進む）。目安を超えても体験は止まらない（警告だけ）。強制終了は動かない体験者への保険で 0 = 無効。
演出を待つ猶予＝終わる条件が揃ったあと、演出が始まるのをこの秒数だけ必ず待つ（もどりの区間に置いた演出はこの中で始まらないと出ない）。演出を見せ切る上限＝そのとき走っている演出を最後まで見せる上限。どちらも 0 なら Quest の既定（3s / 60s）。
撮像の質（show.json feel）。実機でしか見えない（この卓のプレビューには出ません）。画像加工（post）と違って時間で動くので別系統にしてあります。明るさの追従は、映っている範囲では何も変わっていないのに画が明るくなる／暗くなる、という読まれ方をします。
導入の遷移演出（show.json run.intro）。段は体験者が見る順に 現実 → 格下げ → 構造 → 枠 → すり替え。「現実」を削ると次の格下げが変化として読めなくなる。「構造」は輪郭だけの世界に壁・床とカメラの位置を重ねる段で、線が実物に重なるかは位置合わせの現地検証も兼ねる（重ならなければそこで中止して再登録する）。上限を超えた分は段を飛ばして枠を出す。「構造」の壁の線は layout.room からしか出ない — フロアマップの 🧱 部屋で壁を引いていないと床の外周とカメラの印だけになる（床の寸法は［🎯 姿勢を合わせる］で測る）。いつ始まるかは「始まる合図」で決める — 📏 通過ラインを選べば被った体験者がその線を横切った瞬間に始まり（歩いて入ってくる動きのまま始められる）、選ばなければフロアマップの 🎬 開始位置の円に 0.5 秒留まると始まる。どちらも位置合わせ済みが前提で、未登録ならスタッフの ⏭ だけで始まる。

🎬 cue 手動発火 保存済み cue を選んで Quest に即時オーバーレイ（control.activeCue）。タイムラインの自動発火より優先され、その間は自動発火が抑止される。動画は再生終了で自動的にライブへ復帰。cue の作成・編集は 🎬 事前オーサリングのタイムラインで行う。

🕹 ショーシミュレーション（実機なし検証） 左のフロアマップを 🚶 歩かせる にしてドラッグすると、体験者が歩いたものとしてショーが実時間で進む。ゾーン確定（最小滞在）・周回・区間・演出の発火（enter/exit・取り逃し・once・同時1本・watchdog）・画面のクールダウンまで、Unity と同じ判定ロジックで動く（golden トレースで機械照合済み）。「いま画面に映っているもの」は卓の合成器（Quest と同じ式）で実画表示する（ライブはカメラ接続時のみ。素材・マスク・画像加工は未接続でも出る）。歩きを記録してシナリオに保存すれば、同じ歩き方をワンクリックで再実行できる。体感・遅延・VR 提示・位置合わせは検証できないので実機確認は別途必要。

🎭 CG 人形映像の上に立たせる 3D の定義

🎭 CG 人形（映像の上に立たせる 3D） 演出のカットに重ねる人形。体験者のハンドトラッキングで腕が動く（プレハブに ShowActorRig が付いていれば自動）。立ち位置は「体験者の位置（分身）」か「決めた位置」をカットで選ぶ。実カメラの姿勢を著作したカメラでだけ出る（カメラ列の 📐 欄・フロアマップの 📐 モード）。プレハブは Unity の Tools/FixedCamVr/Setup/Build Show Actor Prefab で humanoid の FBX（Mixamo 等）から作る。
