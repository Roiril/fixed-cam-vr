# 廻リ視のサイト制作

ユーザーの2026-09-15以降の指示を優先する。以下は2026-09-22の追加指示を反映した状態。

- 2026-09-22の指示：カメラと壁の写真はPC内の実際の撮影写真を使う。出典は `assets/SOURCES.md`。ヒーローは同日追加指示の「今のウェブのヒーローの見た目」を維持する。
- 黒背景に既存の題字を立体表示する入口を置く。タップで題字が割れ、ヒーローへ進む。動きを減らす設定とスキップに対応。旧 `scene.js` は使わない。
- 固定視点の説明の後に、制作中の視点切り替えサイトを埋め込む受け皿を置く。`experience-config.js` の `gameUrl` が空なら準備中の紹介のみ。未完成のサイトを勝手に組み込まない。
- 実機の演出映像は記録の後。ネタバレを含む折り畳みを開くまで映像とポスターを読まない。映像は手動で再生する。出典は `assets/FOOTAGE.md`。

- 初めて訪れる人が体験を理解できる順序で書く。現実の自分をカメラ越しに見る説明から、ゲーム史の説明へ飛ばない。
- 本文は「キービジュアル → 固定視点 → 視点体験の紹介 → 調査依頼 → 記録 / ARCHIVE → 実機映像 → クレジット」。記録にはユーザー指定の IVRC2026 優勝・DCEXPO賞・DCEXPO2026 の2026年11月展示予定を載せる。
- 2026-09-19のユーザー指示：記録とクレジットは参考画像（工業ラベル・ダイカットタグ・銘板）に倣ったデジタル表現にする。装飾の文字列は実在の事実から機械的に導いたものだけを置く。当て字の型番・架空の組織・煽り文句は引き続き禁止。文言（役割・人名・受賞・展示予定）は変えない。
- 記録の後にクレジットを置く。2026-09-15のユーザー指定の10項目を使う。役割と「白石」「五島」「チーム」の文言は変えない。
- 「固定画角ゆえの死角」「画面の中の自分」は使わない。「生成イメージ」の表示は不要。
- 固定視点カメラは1→2→3→1の順で6秒ごとに自動切替する。手動選択とブラウザの戻る・進む操作の後は6秒から再開する。ページが非表示の間は止める。自動切替のON/OFF操作は追加しない。
- 説明を増やして補わない。断片的な用語や独自の煽り文句を足さない。自然な日本語の短い文にする。
- 調査依頼は「怪異調査員として、呪われた壁の調査に向かう。」と伝える。依頼書には既存の `docs/onsite/handout.pdf` の原稿を使う。組織名や事件を作らない。
- 人形をキービジュアル以外に多用しない。筆文字と暗い色調を保つ。
- 参考は第四境界のサイト。別セッションの旧サイトを参考にしない。
