# 廻リ視のサイト制作

ユーザーの2026-09-15以降の指示を優先する。以下は2026-09-22の追加指示を反映した状態。

- 2026-09-22の指示：カメラと壁の写真はPC内の実際の撮影写真を使う。出典は `assets/SOURCES.md`。ヒーローは同日追加指示の「今のウェブのヒーローの見た目」を維持する。
- 黒背景に既存の題字を立体表示する入口を置く。2026-09-22の修正指示で、案内は「タップ」または「クリック」の行為だけ。画面のどこからでも開始する。Quest本体の `IntroFractureMesh.cs` / `IntroFractureTime.hlsl` / `IntroFracture.shader` のガラスが割れて戻る5秒の動きに合わせる。着地した部分から実HTMLを見せる。動きを減らす設定とスキップに対応。旧 `scene.js` は使わない。
- 2026-09-22の追加指示：「破片はタイトル画面の破片」。分離と帰還の途中も実際の題字の白い筆跡と赤い印を保つ。材質で黒く塗り潰さない。定位置に着いた破片からウェブ表示へ変わり、中央の最後の破片で揃う。途中の描画を止め、題字が残ることと着地ごとの変化を目で確認する。
- 2026-09-22の追加指示：`127.0.0.1:4175`の完成した視点切り替え体験を架空の古い携帯ゲーム機の画面内で遊べるようにする。本体はユーザー参照画像から画像生成。`perspective-game/`に同梱し公開環境でlocalhostを参照しない。電源を入れてからiframeを作り、閉じたら破棄する。
- 実機の演出映像は展示履歴の後。ネタバレを含む折り畳みを開くまで映像とポスターを読まない。映像は手動で再生する。出典は `assets/FOOTAGE.md`。

- 初めて訪れる人が体験を理解できる順序で書く。「固定視点とは」と「実世界×固定視点」を見出しで分ける。
- 2026-09-24の追加指示：展示履歴の下に指定のYouTubeトレイラーを置き、2026.09.01時点で作成した古いバージョンと添える。ゲーム機は初回から電源を入れ、固定視点で開く。
- 2026-09-23の追加指示：本文は「キービジュアル → 視点の説明 → 実世界での固定視点 → ストーリー → 展示履歴 → こだわりのVR演出 → クレジット」。章の見出しは2026-09-24の指定に従う。実世界の章はレトロテレビに映るカメラ展示を含む。ストーリーは「あなたは、怪異調査員として、呪われた壁の調査に向かう。」。ゲーム起動後の終了ボタンは「電源を切る」。ヒーローの「この視点に入る」は矢印なし。視点切替への追加リンクを置かない。現実がスクリーンになる動画は冒頭4秒を除く。
- 展示履歴にはユーザー指定の IVRC2026 優勝・DCEXPO賞・DCEXPO2026 の2026年11月展示予定を載せる。クレジット見出しは日本語のみ。クレジットのコード図案とURLは置かない。スマホでも項目を左右2列に並べる。
- 2026-09-19のユーザー指示：展示履歴とクレジットは参考画像（工業ラベル・ダイカットタグ・銘板）に倣ったデジタル表現にする。装飾の文字列は実在の事実から機械的に導いたものだけを置く。当て字の型番・架空の組織・煽り文句は引き続き禁止。文言（役割・人名・受賞・展示予定）は変えない。
- 展示履歴と演出映像の後にクレジットを置く。2026-09-15のユーザー指定の10項目を使う。役割と「白石」「五島」「チーム」の文言は変えない。
- 2026-09-22の修正指示：ストーリー内の依頼書の写真はカメラ01と同じ正面カーテンを人形視点の100%の加工で見せる。固定視点の映像は既存のレトロテレビ内に表示する。カメラ01〜03すべてにQuest本体の上映設定を移した加工済み写真を使う。追加のCSS色補正を重ねない。制作名は `Roil Studio`。連絡先は `rinkyouaoi@gmail.com`。
- 「固定画角ゆえの死角」「画面の中の自分」は使わない。「生成イメージ」の表示は不要。
- 固定視点カメラは1→2→3→1の順で6秒ごとに自動切替する。手動選択とブラウザの戻る・進む操作の後は6秒から再開する。ページが非表示の間は止める。自動切替のON/OFF操作は追加しない。
- 説明を増やして補わない。断片的な用語や独自の煽り文句を足さない。自然な日本語の短い文にする。
- 調査依頼は「怪異調査員として、呪われた壁の調査に向かう。」と伝える。依頼書には既存の `docs/onsite/handout.pdf` の原稿を使う。組織名や事件を作らない。
- 人形をキービジュアル以外に多用しない。筆文字と暗い色調を保つ。
- 参考は第四境界のサイト。別セッションの旧サイトを参考にしない。
