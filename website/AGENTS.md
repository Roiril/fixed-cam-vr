# 廻リ視のサイト制作

ユーザーの 2026-09-15 の指示を優先する。

- 初めて訪れる人が体験を理解できる順序で書く。現実の自分をカメラ越しに見る説明から、ゲーム史の説明へ飛ばない。
- 現在の構成は「キービジュアル → 固定視点 → シナリオ」まで。続きは依頼されてから追加する。
- 「固定画角ゆえの死角」「画面の中の自分」は使わない。自動切り替え機能と「生成イメージ」の表示は不要。
- 説明を増やして補わない。断片的な用語や独自の煽り文句を足さない。自然な日本語の短い文にする。
- シナリオは、調査員として呪われた壁の調査を依頼される設定。依頼書には既存の `docs/onsite/handout.pdf` の原稿を使う。組織名や事件を作らない。
- 人形をキービジュアル以外に多用しない。筆文字と暗い色調を保つ。
- 参考は第四境界のサイト。別セッションの旧サイトを参考にしない。
