# 廻リ視のサイト制作

ユーザーの2026-09-15以降の指示を優先する。以下は2026-09-25の追加指示を反映した状態。

- 2026-09-25の指示：レトロテレビには、git `b2d9bce3` の架空の廊下3視点を別名 `camera-fiction-01.webp` 〜 `03` として使う。実写真原本と `camera-01.webp` 〜 `03` は保持する。調査依頼は実写真由来の `camera-01-doll.webp` を使う。出典は `assets/SOURCES.md`。
- 初回は `index.html` 先頭の同期bootstrapで本文を隠し、黒い読み込み画面を最大15秒表示する。音声と題字の準備後だけ入口を開く。スキップ、Escape、準備失敗では本文へ進み、遅れて準備が終わっても入口へ戻さない。
- 黒背景に既存の題字を立体表示する入口を置く。案内は「タップ」または「クリック」の行為だけ。画面のどこからでも開始する。Quest本体の `IntroFractureTime.hlsl` / `IntroLogic.cs` / `SoundCueLogic.cs` / `SfxPlayer.cs` と `show.json` を `scripts/sync-entrance.mjs` で同期し、5秒の動きと1本の音を合わせる。非表示中は時間と音を止める。スキップでは音も止める。動きを減らす設定とWebGL非対応では短い無音フェードにする。旧 `scene.js` は使わない。
- 2026-09-22の追加指示：「破片はタイトル画面の破片」。分離と帰還の途中も実際の題字の白い筆跡と赤い印を保つ。材質で黒く塗り潰さない。定位置に着いた破片からウェブ表示へ変わり、中央の最後の破片で揃う。途中の描画を止め、題字が残ることと着地ごとの変化を目で確認する。
- 2026-09-22の追加指示：`127.0.0.1:4175`の完成した視点切り替え体験を架空の古い携帯ゲーム機の画面内で遊べるようにする。本体はユーザー参照画像から画像生成。`perspective-game/`に同梱し公開環境でlocalhostを参照しない。電源を入れてからiframeを作り、閉じたら破棄する。
- 実機の演出映像は展示履歴の後。ネタバレを含む折り畳みを開くまで映像とポスターを読まない。映像は手動で再生する。出典は `assets/FOOTAGE.md`。

- 初めて訪れる人が体験を理解できる順序で書く。「固定視点とは」と「実世界×固定視点」を見出しで分ける。
- 2026-09-25の追加指示：指定のYouTube動画をヒーロー直下の独立した `#trailer` に置く。2026-09-26の指示で章見出しは「予告動画」とし、他章と同じ見出しサイズに揃える。「この映像は2026.09.01時点で作成したものです。」「DCEXPOに向けた新しい予告動画を作成中です。」と添える。ゲーム機は初回から電源を入れ、固定視点で開く。
- 本文は「キービジュアル → 予告動画 → 固定視点とは → 実世界×固定視点 → ストーリー → 展示履歴 → 演出一覧 → クレジット」。ヒーローの「この視点に入る」と「固定視点とは」直下の説明は置かない。予告動画と演出一覧は「ネタバレを含みます」だけを共通の注意文にする。現実がスクリーンになる動画は冒頭4秒を除く。
- 「実世界×固定視点」では、ヘッドセットに届く映像の説明、テレビ上の「CAMERA VIEW / 固定視点」、テレビ下のカメラ選択案内を置かない。
- 展示履歴にはユーザー指定の IVRC2026 総合優勝・DCEXPO賞・DCEXPO2026 の2026年11月展示予定を載せる。クレジット見出しは日本語のみ。クレジットのコード図案とURLは置かない。スマホでも項目を左右5項目ずつに並べ、320pxでも役割と氏名を同じ行に保つ。
- 2026-09-19のユーザー指示：展示履歴とクレジットは参考画像（工業ラベル・ダイカットタグ・銘板）に倣ったデジタル表現にする。装飾の文字列は実在の事実から機械的に導いたものだけを置く。当て字の型番・架空の組織・煽り文句は引き続き禁止。文言（人名・受賞・展示予定）は変えない。役割名は2026-09-26の指示を反映する。
- 展示履歴と演出映像の後にクレジットを置く。10項目は白石の6項目を上3段にまとめ、残り4項目を下2段に置く。2列の中央には他の飾り線と同じ細く淡い区切り線を置き、赤線は置かない。縦書きの飾りはスマホでも残す。役割と氏名は改行しない範囲で大きくし、連絡先は控えめな等幅書体で整える。「白石」「五島」「チーム」の文言は変えない。
- ストーリー内の依頼書の写真はカメラ01と同じ正面カーテンを人形視点の100%の加工で見せる。固定視点の映像は既存のレトロテレビ内に表示する。制作名は `チーム：Roil Studio`。その直下に `白石大晴 / Kim Hyunmin / 堀越 康平 / 五島 慶人` を置く。連絡先は `rinkyouaoi@gmail.com`。メールの下にポートフォリオ `https://my-portfolio-ruby-delta-87.vercel.app/` を置く。担当一覧の氏名は右側に少し余白を設ける。
- 「固定画角ゆえの死角」「画面の中の自分」は使わない。「生成イメージ」の表示は不要。
- 固定視点カメラは1→2→3→1の順で6秒ごとに自動切替する。手動選択とブラウザの戻る・進む操作の後は6秒から再開する。ページが非表示の間は止める。自動切替のON/OFF操作は追加しない。
- 説明を増やして補わない。断片的な用語や独自の煽り文句を足さない。自然な日本語の短い文にする。
- 調査依頼は「怪異調査員として、呪われた壁の調査に向かう。」と伝える。依頼書には既存の `docs/onsite/handout.pdf` の原稿を使う。組織名や事件を作らない。
- 人形をキービジュアル以外に多用しない。筆文字と暗い色調を保つ。
- 参考は第四境界のサイト。別セッションの旧サイトを参考にしない。
