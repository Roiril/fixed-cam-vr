# 廻り視 公式サイト

「視点を、置き去りにする。」を主題にした、体験型ホラー作品「廻り視」の公式サイトです。現在の像と過去の像を同じ空間で見る作品の構造を、3つの固定視点を通じてWeb向けに表現します。実機録画の再現ではありません。

## 操作

- ポインター操作、タッチ操作、キーボード操作に対応します。
- 音は任意です。初期状態では再生しません。
- OSの「視差効果を減らす」設定を尊重します。画面内の操作でも動きを減らせます。
- Loading画面は「先に進む」でスキップできます。

## 開発

追加パッケージは不要です。Node.jsで次のコマンドを実行します。

```console
npm run dev
npm run dev -- --port 4174
npm run check
npm run build
```

開発サーバーは既定で `http://127.0.0.1:4173/` を使います。`npm run check` は必要なファイル、HTML内のローカル参照、IDの重複、JavaScriptの構文を検査します。

`npm run build` は公開対象を `dist/` へコピーします。通常の公開物は `dist/` です。そのまま静的ホスティングへ配置できます。このリポジトリの作業では外部公開や予約受付を行いません。

公開ドメインの確定後、`og:image` と `twitter:image` はそのドメインを含む絶対URLへ変更します。

## 素材と展示情報

画像はプロジェクトの既存 `Assets/` と `output/imagegen/` にある制作素材をもとに、Web掲載用として選定・加工したものです。DCEXPOは2026年11月18日から20日まで幕張メッセで開催され、入場は無料登録制です。「廻り視」の具体的な体験枠と予約方法は未確定です。

配信用の画像は `assets/` としてリポジトリに含まれます。原画像を再び書き出す場合は、このPCにある既存の `output/` 素材が必要です。
