明滅を含みます。

導入

  1. 暗闇の奥に黒いテレビが現れて、目の前まで寄ってくる。

    PC上の再現映像 / 音声なし / 2秒

  2. テレビが点いて、監視カメラの映像が映る。

    PC上の再現映像 / 音声なし / 4秒

一周目

  1. 壁に、血の手形が滲む。

    PC上の再現映像 / 音声なし / 5秒

  2. 異変を報告すると、手形は消える。

    PC上の再現映像 / 音声なし / 5秒

二周目

  1. 幕に、顔のようなシミが滲んで広がる。

    PC上の再現映像 / 音声なし / 6秒

  2. 幕が膨らんで、笑う顔がせり出す。幕の縁から人形が覗く。

    PC上の再現映像 / 音声なし / 7秒

  3. 画面ごと、古い子供部屋へ飛ばされる。人形が畳に落ちて、首だけがこちらを向く。

    PC上の再現映像 / 音声なし / 4秒

  4. 人形の目線が割り込む。自分の背中が、近づいてくる。

    PC上の再現映像 / 音声なし / 3秒

  5. 画面が砂嵐になって、警告が出る。案内役の顔が人形に変わる。

    PC上の再現映像 / 音声なし / 11秒

三周目

  1. 部屋が伸び縮みして、傾く。

    PC上の再現映像 / 音声なし / 6秒

  2. 自分が立っているはずの場所に、人形が立っている。

    PC上の再現映像 / 音声なし / 4秒

  3. 一周目の録画が流れる。そこに居たのは、人形だった。

    PC上の再現映像 / 音声なし / 6秒

  4. 暗闇の奥から、テレビが次々に寄ってきて周りを埋める。

    PC上の再現映像 / 音声なし / 4秒

最後

  1. 画面の半分を、人形の群れが埋める。

    PC上の再現映像 / 音声なし / 5秒

  2. 案内役が、歩くのを止める。

    PC上の再現映像 / 音声なし / 2秒

  3. 最後の報告で人形が消えて、現実に戻る。

    PC上の再現映像 / 音声なし / 3秒

  4. 人形がこちらを向く。背を向けて、奥へ消える。

    PC上の再現映像 / 音声なし / 14秒

終幕

  1. テレビの電源が落ちて、結果が出る。

    PC上の再現映像 / 音声なし / 7秒

  2. 報告しないまま歩き続けると、画面は黒に落ちる。

    PC上の再現映像 / 音声なし / 5秒
